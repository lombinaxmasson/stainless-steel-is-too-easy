# 大型 AOD · 炉体方案 02

这版按世界方块的**接触面**对齐接口。圆管颈和法兰直接长在炉身上，不再使用独立方块端口箱。模型去掉了整机底座，炉底本身以 3×3 平面贴合下方燃烧室；炉身保留连续两格高的等截面柱段，前侧可连接浇铸口，顶部可翻盖投料。

此模型已接入游戏，具有六个材料等级、HU、双气口、投料炉盖及浇铸能力。本目录保留原始模型与离线预览。

## 文件

- `large_aod.obj`：关盖状态，16 个命名对象，3,366 个三角面。
- `large_aod_open.obj`：同一模型的开盖状态，便于静态导入和检查。
- `large_aod.mtl`、`large_aod_atlas.png`：共用单材质和 256×128 像素图集；使用最近邻采样。
- `ports.json`：接口平面范围、法向、整格连接位置、模具位置、柱段和炉盖转轴。
- `preview.html`：离线 WebGL 2 预览，可旋转、缩放、开关炉盖、查看炉底和点选接触面。
- `preview.png`：新版静态预览。

OBJ、MTL、PNG 保持在同一目录即可导入 Blender。开盖 OBJ 是可选状态快照，不要把两份完整炉体叠放。制作动画时使用关盖模型中的独立 `lid` 对象和清单里的轴心；OBJ 文件本身不存动画。

## 炉体与网格

1 个模型单位等于 1 个世界方块。Y 向上，正面为 −Z，炉体中心 X/Z 为 `(0.5, 0.5)`。原点 `(0,0,0)` 位于受热平面，所有格坐标均表示方块最小角。

- **炉底**：平面 `Y=0`，X、Z 都覆盖 `[-1,2]`，面积为 9。九个四边形无缝拼成连续的 3×3 接触面；没有模型伸入下方 Y<0。
- **两层柱段**：`Y=1～2` 与 `Y=2～3` 使用完全相同的十二边截面，外壳自 `Y=3.2` 才开始收肩。加强筋沿柱段竖直布置，进气和浇铸接头在柱段侧面。
- **占用范围**：关盖几何约 `[-1.82,0,-2]` 到 `[3,5.8976,2.36]`；开盖最高约 7.566 格。按整数包围盒预留 5×5×6 格，开盖时上方预留至第 8 格。这不是要求玩家搭一个实心结构。
- **外观附件**：薄检修踏板、爬梯、吊耳和铰链均附着于炉身。预览背景投影平面与接口外侧的线框格都不是 OBJ 的组成部分。

## 接触面和浇铸

| 功能 | 接触面范围 | 外侧连接格 | 接口形状 |
| --- | --- | --- | --- |
| HU 输入 | `Y=0`，`X/Z=-1～2` | 九格 `(x,-1,z)`，x/z 取 −1、0、1 | 炉底完整 3×3 平面 |
| 氧气输入 | `X=3`，`Y=1～2`，`Z=-1～0` | `(3,1,-1)` | 圆管颈、八角压环、0.12 格厚方形端法兰 |
| 氩气输入 | `X=3`，`Y=1～2`，`Z=1～2` | `(3,1,1)` | 圆管颈、八角压环、0.12 格厚方形端法兰 |
| 浇铸输出 | `Z=-2`，`X=0～1`，`Y=1～2` | 浇铸口 `(0,1,-3)`；模具 `(0,0,-3)` | 耐火短颈与完整 1×1 平接面 |
| 投料开口 | `Y=5`，`X/Z=0～1` | `(0,5,0)`，需开盖 | 圆形炉口内的中央一格通道，非实体面 |

气体与浇铸端面的几何是完整平面；中央孔的暗部通过贴图表现，不在接触面上挖掉面积。其余管颈和压环保持低面数圆形。

浇铸布局参考本地 GT6CE 的 `CrucibleFaucetBlockEntity.pullFromCrucible`：从坩埚侧壁接浇铸口，再向下送入模具。运行时控制器位于原模型 (0,1,−2) 的浇铸口格，通过 SDK 坩埚接口供给原版龙头。没有增加普通流体管出钢、专用炉渣箱或额外电力接口。

气体接口暂以 O₂、Ar 区分美术位置，最终介质限制由机器逻辑决定。

## 炉盖

`lid` 对象绕沿 X 的轴旋转，轴心为 `(0.5,5.1,1.84)`；关闭为 0°，打开为 +105°。预览中的按钮会真正旋转炉盖，而非隐藏它。打开后中央投料连接格无遮挡；关闭后投料标注与点选关闭。预览尊重系统的减少动态效果设置。

## 生成和检查

在仓库根目录运行，依赖 Python 3 和 Pillow：

```powershell
python scripts/models/build_large_aod.py
```

`scripts/models/aod_vessel.py` 定义炉体几何，`build_large_aod.py` 负责图集、OBJ、清单及预览导出。固定随机种子确保贴图可复现。生成器检查：

- 坐标与法向有效、UV 位于图集内。
- HU 面面积恰好为 9，两个气体及浇铸面各为 1，且接触面共面、边界为整数。
- 两个完整柱形层的十二个截面顶点一致。
- 下方九格、气管连接格、浇铸口和模具格没有模型伸入。
- 开盖后顶部投料格畅通。

交互检查依赖 Python Playwright 和 Chromium：

```powershell
python scripts/models/inspect_large_aod.py --output .\build\large-aod-qa
```

已覆盖旋转、缩放、炉底视图、接触面点选、浇铸面定位、开关盖动画、关盖后关闭投料标注、减少动态效果设置、736/360 像素宽度与明暗主题。

本模型沿用第一版总结的 HBM 工业风格：暗灰钢板、铆钉、法兰、耐火内衬和少量黄色扶手。网格和贴图均为本项目原创，未复制 HBM 资产，按仓库 LGPL-3.0-or-later 许可提供。`scripts/models/install_large_aod.py` 将此模型安装到游戏资源并生成六套材料贴图。
