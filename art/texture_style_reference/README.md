## 按实际宽高绘制模型贴图

### 先展开，再画材质

1. 取原网格的一个平面多边形。在平面内取互相垂直的单位轴 `u` 和 `v`。立面尽量令 `v` 沿世界竖直方向在该面上的投影，横面沿主要结构边取轴。共享一张板的三角形使用同一对轴和同一个原点。
2. 从顶点 `p` 减去原点 `o`，再投影到两个轴。以一格 64 像素为例，像素坐标为 `64 × ((p − o) · u, (p − o) · v)`。以投影的实际包围框分配图块，UV 坐标保留小数。绘制和打包时再为像素取整及采样边距留空间。
3. 共面的面板、扇形盖和表盘可以合成一个图岛。跨折角时沿共享边切开或展开，再按每片自己的平面长度采样。斜肩的高度取斜边长度。圆筒用各分段的实际宽度或沿周向累计宽度。管道的长边沿轴向铺。
4. 板面留出浅压边、接缝和短筋。窄箍、法兰边、切角和管口按尺寸画金属基底或一条收边。长条上沿长度方向延续笔触，避免把带四角铆钉的整张方板压进一条窄边。
5. 图块四周留 3 像素的采样边距，用最近的边缘颜色填满。铺入图集时保留既定像素比例，OBJ 的 `v` 坐标按图集原点换算，使用最近邻采样。分配图岛、贴图和导出 OBJ 要由同一套输入一起生成。

小型 AOD 的主侧面是 0.75×1 格，所以画成 48×64。0.1768×0.96875 格的切角面展开约为 11.3×62 像素，可以画成竖直金属窄条。流化床的筒壁、横箍与纵筋分别展开，宽板的接缝在视角切换时仍与实际面边对齐。

### 铆钉和功能图案

- 先排接缝，再沿接缝定位钉头。示例使用 5×5 像素的阶梯圆形遮罩，对应每边 5/64 格。轮廓固定，只调高光和阴影适配底色。计算与各边的距离，装不下钉头和留边时省略。
- 立面按视角自然缩短，图岛内钉头的宽高仍相等。已有立体螺栓的炉盖、检修口和法兰可以保留几何螺栓，板面图案留白。
- 铭牌、接口、刻度和指示灯单独排版。先定板面，再按原比例放标志。状态变化在原有亮灯区域处理，工作和空闲面保持同一外壳与接口位置。

## 离线检查

- OBJ 逐三角形核对顶点、法线、面序和分组，确认原来的炉盖、检修件、动画组和接口仍能按原方式使用。
- 用 UV 差乘图集宽高得到像素边向量，再与世界空间的边向量比较。边长之比应与该材质的设定密度一致，两个方向也应等比例。可用两组边向量的 Gram 矩阵检验长度和夹角。
- 观察同机位整机图，再放大炉盖、切角、筒壁、窄箍、法兰和铭牌。用方块贴图的平铺图检查连续接缝。这里的对照图来自离线渲染。

## 正式资源生成入口

在仓库根目录运行。生成脚本与部分早期图层位于本地维护的 `scripts/models/`，新检出的工作副本需要另外同步这些输入。B 方块面使用 Pillow，C 图集的几何展开还需要 NumPy。

```powershell
python scripts/models/build_block_style_b.py
python scripts/models/build_small_furnaces.py --install
python scripts/models/build_large_aod.py --install
python scripts/models/install_fluidized_bed.py
python scripts/models/build_irradiation_reactor.py
python scripts/models/install_irradiation_reactor.py
python scripts/models/build_chemical_looping_beds.py --install-runtime
```

B 的八张 64×64 样板来自本页归档。原有方块的面板图案、状态颜色和材料配色从旧图层提取。流化床与 HU 部件的 OBJ 使用同一张 C 图集，其方块面由 B 的生成入口独立输出。大型 AOD、靶件照射反应堆等使用方块形态时仍由各自方块模型读取 B 贴图。

精密激光加工工作站、离子注入机、电子束直写机、粉末床熔融打印机、煤气化炉和唱片刻纹机目前沿用 GT6 风格外壳，配合现有的能量入口。生成器直接复制换风格前的完整贴图，包含各自的运行态。光纤拉丝机和光纤状态探头从 `fiber_controls` 读取各自用到的 B 风格面板。
