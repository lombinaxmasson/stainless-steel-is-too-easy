# 小型 AOD 与 VAR · 模型原型 03

这两套模型延续大型 AOD 的低面数工业风格，炉身改为四个宽平面加四个切角面的八面柱。**底面完整 1×1，四个主侧面各保留 0.75 格宽、完整 1 格高的连续平面**。连接面贴合世界方块边界，铆钉、标志、接口圈和仪表画在贴图里，不占用平整面积。

当前交付为 OBJ、贴图、接口清单和交互预览。AOD 已包含项目现有的六档材料自动换色。没有替换现有游戏模型或修改机器行为。

## 外观

- **小型 AOD**：钢色八面柱下壳，深色切角装甲、耐火炉口、黄色把手、短气路和可翻开的炉盖。主模型 806 个三角面、14 个对象。
- **VAR 电弧炉**：铜色八面柱炉套，深铜色切角装甲、陶瓷密封/绝缘环，石墨色电极、铜夹头、侧立柱及横梁滑架。开盖时先抬起电极，再移至前右角，最后翻开炉盖。主模型 1,086 个三角面、18 个对象。
- **正面标志**：依据用户提供的 GT6CE 参考图重绘像素轮廓，保留青绿色主体和右下深色投影；AOD 中央加入琥珀色炉火，VAR 加入浅色电弧。标志直接在平面贴图内，另附可编辑 SVG。
- **文字与光泽**：纹理从原生 32 像素小块重新绘制为 64 像素小块；AOD/VAR 使用手绘 5×7 字形、2 像素笔画。金属度与粗糙度贴图区分钢壳、铜、陶瓷、耐火砖及油漆标志。预览提供随视角变化的高光和简化摄影棚反射。

模型几何及机器表面纹理由本项目生成，没有复制 HBM 顶点或贴图。GT6CE 标志变体源自用户参考图，未将原标志归为本项目原创；来源也记录在 `interfaces.json` 的 `front_mark` 字段。

## 文件

`aod/` 和 `var/` 各包含：

- `small_aod.obj` / `small_var.obj`：关盖状态。
- 对应的 `_open.obj`：开盖状态快照，供静态软件查看。
- 对应的 `.mtl` 与 `_atlas.png`：按表面类型分配材质，共用 512×256 像素颜色图集，使用最近邻采样。
- `_surface.png`：R=金属度，G=粗糙度，B=自发光；三个通道都是线性数据。
- `_metallic.png` / `_roughness.png`：单独的灰度参数图，供材质编辑器使用。
- `_specular.png`：OBJ/MTL 的镜面反射近似图；MTL 同时提供各表面的 `Ns`。
- `_neutral.png` / `_tint_mask.png` / `_neutral_surface.png`：生成材质变体所用的中性底图、染色遮罩和原始表面参数；遮罩白色区域染色、黑色区域保留。AOD 的原始表面参数在白色区域使用对应等级参数替换。VAR 遮罩为全黑。
- `gt6ce_aod_mark.svg` / `gt6ce_var_mark.svg`：与图集中标志使用同一像素网格的透明矢量图。
- `interfaces.json`：完整面、四侧保留区、投料通道、分组、运动参数和检查结果。
- `preview.png`：静态预览。

根目录的 `preview.html` 可离线打开，需要 WebGL 2。上方切换 AOD/VAR，在 AOD 模式可选择炉壳材料；下方可检查底面和四侧，支持旋转、缩放、点选面和开关炉盖。

导入时把 OBJ、MTL、PNG 保持在同一目录；只导入关盖或开盖其中一份完整模型，避免叠放。OBJ 不保存动画，运动对象与参数见清单。

OBJ/MTL 的光泽是兼容性近似，各软件对 `map_Ks`、`Ns` 的支持不同。在支持金属度/粗糙度材质的编辑器中，将 `_atlas.png` 接入颜色（sRGB），将 `_metallic.png`、`_roughness.png` 作为非颜色/线性数据接入对应输入。预览直接读取表面参数图；其高光不会自动出现在未接入相应渲染的 Minecraft 中。

## AOD 材料生成

`aod/variants/<等级>/` 包含每档可直接导入的关盖 OBJ、开盖 OBJ、MTL 和五张贴图。根目录 `aod/small_aod.obj` 默认使用钢。各等级共用同一几何、UV 和固定装饰，仅改变遮罩内的炉壳颜色及表面参数。

| 等级目录 | 材料 | GT6CE 原始颜色 |
| --- | --- | --- |
| `steel` | 钢 / Steel | `#828282` |
| `stainless_steel` | 不锈钢 / StainlessSteel | `#C8C8DC` |
| `niobium_titanium` | 铌钛合金 / NiobiumTitanium | `#1D1D29` |
| `tungsten_steel` | 钨钢 / TungstenSteel | `#6464A0` |
| `tungsten` | 钨 / Tungsten | `#323232` |
| `ta4hfc5` | 碳化钽铪 / TantalumHafniumCarbide | `#208020` |

等级与顺序来自 `common/src/main/java/com/lombinaxmasson/ssite/machine/AodTier.java`；颜色来自相邻 GT6CE 的 `core/src/main/java/gregtech/content/material/generated/CompoundMaterials.java` 和 `ElementMaterials.java`。配置快照位于 `scripts/models/aod_materials.json`，新增或删去等级但尚未配置时生成器会报错。

为保留深色材料细节，艺术用染色值按每通道 `round(56 + 0.70 × 原始颜色)` 生成，再乘以中性底图；清单同时记录 `color` 原始色与 `tint_rgb` 实际染色值。粗糙度、金属度为美术参数，不是实测值。GT6CE 标志、字母、仪表、气路识别色、耐火砖和陶瓷不参与换色。

## 坐标和接触面

1 单位 = 1 个世界方块。下方炉体方块为 `(0,0,0)`，上方炉盖方块为 `(0,1,0)`；Y 向上，北面为 −Z，水平中心为 `(0.5,0.5)`。

| 面 | 平面 | 保留范围 | 实际面积 | 外侧相邻方块 |
| --- | --- | --- | --- | --- |
| 底 | Y=0 | X、Z 均为 0～1 | 1 | `(0,-1,0)` |
| 北 / 正面 | Z=0 | X=0.125～0.875，Y=0～1 | 0.75 | `(0,0,-1)` |
| 东 | X=1 | Z=0.125～0.875，Y=0～1 | 0.75 | `(1,0,0)` |
| 南 | Z=1 | X=0.125～0.875，Y=0～1 | 0.75 | `(0,0,1)` |
| 西 | X=0 | Z=0.125～0.875，Y=0～1 | 0.75 | `(-1,0,0)` |

下方炉身高度为完整 1 格，四个主侧面连续贯通 Y=0～1。每侧两端各切去 1/8 格，形成四条斜面；最底部保留 1/32 格厚的完整方形收边，让底面仍完整覆盖 1×1。收边全部位于炉体自身方块内，不增加占地。侧面的 UV 使用 48×64 像素区域，匹配 0.75×1 的实际宽高，避免标志被横向压扁。

上沿、炉盖和电极机构保持在原有上方方块中；两台机器开、关盖及采样动画位置均位于 `[0,0,0]` 到 `[1,2,1]` 内。

侧面图案只是外观提示，不将能力固定到单一方向。现有代码 `SsiteMachines` 为 AOD 定义 HU 与 KU 输入，VAR 定义 EU 输入；两者侧面均可进气。这里保留这些用途的几何空间，也方便后续挂浇铸口和仪表，但没有在此原型中实现游戏能力。

顶部炉口为圆形/八角形真实开口，开盖后的中央 `X/Z=0.34～0.66` 投料通道畅通。它不是完整一格平端面。正式接入时应与现有上方炉盖的物品槽、点击和碰撞行为一并适配。

## 动作

两台盖子的 `lid` 组绕 X 轴旋转，轴心 `(0.5,1.16,0.86)`，开启角为 +90°。

AOD 直接翻盖。VAR 分三段：前 30% 将 `electrode` 组上提 0.3；30%～60% 将其平移 `(0.32,0,-0.32)`，停到上方方块的前右角；最后 40% 翻盖。关闭时逆序执行。悬杆 `suspension` 随上提缩短，横向滑架 `carriage` 随移位伸缩。具体变换以 `build_small_furnaces.py::posed` 为准，预览使用相同参数。

这些是美术预览动作。现有 `SsiteLidPart` 只记录开关状态，正式接入时仍需新增对应客户端渲染及动作同步。

## 修改与验证

仓库根目录执行，依赖 Python 3 和 Pillow：

```powershell
python scripts/models/build_small_furnaces.py
```

生成器复用同目录的基础几何方法；输出位于 `art/small_furnaces/`，不会覆盖大型 AOD。固定种子的像素纹理可复现。

也可从当前 GT6CE 源码读取最新材料颜色，在这次生成中覆盖配置快照的颜色值：

```powershell
python scripts/models/build_small_furnaces.py --gt6-root ..\GregTech6CommunityEdition\GregTech6
```

贴图、遮罩、表面参数和像素字的源代码位于 `scripts/models/small_furnace_materials.py`；调整配色无需手工编辑六份 PNG。未来游戏内也可复用中性底图与遮罩，由材料配置驱动同一套着色。

生成时检查底面/四侧面积、侧面完整高度和居中宽度、切角边界、共面性、法向、UV、有限坐标、中央投料通道，以及 41 个动画位置的 1×1×2 边界。

预览检查依赖 Python Playwright 和 Chromium：

```powershell
python scripts/models/inspect_small_furnaces.py --output .\build\small-furnaces-qa
```

检查包括六档与 `AodTier` 对齐、换色不影响固定标志、几何一致、全部 OBJ 索引和 MTL 贴图引用，以及六档预览切换、两机切换、五个连接面的查看与点击、开关盖及 VAR 分段动作、投料口显隐、旋转缩放、开盖时切换机型、减少动态效果设置、736/360 像素宽度及明暗主题。尚未在游戏内加载、验证碰撞或管道/浇铸功能。
