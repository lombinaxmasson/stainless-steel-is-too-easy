# SuperSymmetry 石化与高分子最终产物用途速查表

> 用途定位：**第一阶段只移植“纯石化 + 单体 + 聚合”产线、暂不挂载下游配方时**，用这份表确认每条支线的**终点产物（物品/流体形态）**以及**未来要接去哪个系统**。

---

## 一、纯石化内部就能闭环的副产物（第一阶段即可直接接通）

这些副产物不需要等外部系统（电路、冶金、太空），在石化系统内部就能消化或互转：

| 副产物 / 中间体 | 怎么来的 | 石化内部消化去向 |
|---|---|---|
| **间二甲苯 (`meta_xylene`)** | 二甲苯精馏 + 结晶分离对二甲苯后的母液（占大头） | 催化异构化（ZSM-5 分子筛）直接转回最缺的**对二甲苯 (`para_xylene`)**；少量留着做间苯二甲酸（诺梅克斯）。 |
| **甲苯 (`toluene`)** | BTX 芳烃抽提精馏 | ① 催化歧化 $\rightarrow$ **苯 + 二甲苯**；② 加氢脱烷基 $\rightarrow$ **苯 + 甲烷**（副产**联苯**）。 |
| **C5 馏分 (`c_five_fraction`)** | 裂解汽油抽提芳烃后的轻组分 | 加热二聚后精馏 $\rightarrow$ 拆成**异戊二烯 (`isoprene`)** + **双环戊二烯 (`dicyclopentadiene`)** + **戊烷**。 |
| **双环戊二烯 (`dicyclopentadiene`)** | C5 馏分二聚精馏 | ① 热裂解回**环戊二烯**（再与乙烯合成**降冰片烯 `dustNorbornene`**）；② 与苯 + 降冰片烯聚合成**石油树脂**。 |
| **混合丁烯 (`butene`)** | 蒸汽裂解 / 催化裂化 / 费托合成 | 精馏拆成 **异丁烯 (`isobutylene`)** + **1-丁烯 (`one_butene`)** + **2-丁烯 (`two_butene`)**。 |
| **抽余油 (`reformate_raffinate` / `pyrolysis_raffinate`)** | 重整油/裂解汽油抽提完 BTX 后的非芳烃 | 回流去蒸汽裂解炉当裂解原料，或进汽油调合池。 |

## 二、塑料与热固性树脂终点产物（做出来干嘛用）

| 最终产物 | 上游单体来源 | 需要保留的形态 | 以后接去哪（下游用途） |
|---|---|---|---|
| **聚乙烯 (`Plastic` / PE)** | 乙烯 | 粉、锭、板、箔、流体管 | 基础塑料件、低压电容、早期化工管道、胶带基底。 |
| **超高分子量聚乙烯 (`UHMWPE`)** | 乙烯（Ziegler-Natta / Kaminsky 催化） | 粉、板、纤维 | **防弹插板/高级护甲**、高级盾牌、耐腐蚀储液鼓（Drum）、钻石级背包。 |
| **聚丙烯 (`Polypropylene` / PP)** | 丙烯 | 粉、锭、板、箔 | 耐酸碱塑料鼓、宇航服液冷靴内衬、医疗/生活塑料件。 |
| **聚氯乙烯 (`PolyvinylChloride` / PVC)** | 乙烯 + 氯气 $\rightarrow$ 氯乙烯 | 粉、板、箔、物品管 | **物品管道**、线缆绝缘层、早期软盘外壳、贴片电容薄膜。 |
| **聚苯乙烯 (`Polystyrene` / PS)** | 苯 + 乙烯 $\rightarrow$ 苯乙烯 | 粉、流体 | 多方块**保温墙（Polystyrene Wall）**、与 PPO 共混工程塑料。 |
| **交联聚苯乙烯 (`CrosslinkedPolystyrene`)** | 苯乙烯 + 二乙烯基苯 | 圆珠、板 | ① 磺化/胺化做成**阴阳离子交换树脂与离子交换膜**（超纯水/湿法冶金）；② 配制**失蜡铸造蜡**。 |
| **聚醋酸乙烯酯 (`PVAc`) / 聚乙烯醇 (`PVA`)** | 乙烯 + 乙酸 $\rightarrow$ 醋酸乙烯 | 粉、溶液 | **PVA**：高级陶瓷成型的**有机粘结剂**；继续与丁醛反应做 PVB。 |
| **聚乙烯醇缩丁醛 (`PVB`)** | PVA + 正丁醛 | 粉、板 | 与聚碳酸酯板压制**防弹夹层玻璃（高级透明机壳）**。 |
| **乙烯-醋酸乙烯共聚物 (`EVA`)** | 乙烯 + 醋酸乙烯 | 粉、微型/小型流体软管 | **宇航服液冷内衣的循环水管**、防护服呼吸管；加异丁烯做柴油防凝剂。 |
| **有机玻璃 (`PMMA`)** | 异丁烯 / 丙酮氰醇 $\rightarrow$ MMA | 粉、板 | **光刻胶（Photoresists）成膜树脂**、透明光学件。 |
| **聚碳酸酯 (`Polycarbonate` / PC)** | 双酚 A + 光气 | 粉、板 | **宇航服头盔面罩**、**防弹夹层玻璃**、防暴盾牌观察窗。 |
| **聚对苯二甲酸乙二醇酯 (`PET` / `Mylar`)** | 对二甲苯 $\rightarrow$ 对苯二甲酸 + 乙二醇 | 粉、板、箔、镀铝膜 | **镀铝 Mylar 太空隔热毯**（宇航服隔热层）、超音速降落伞、碳纤维复合材料脱模膜、早期磁带/软盘。 |
| **酚醛树脂 (`Phenolic` / 电木)** | 苯酚 + 甲醛 | 低聚物液体、浸渍板 | ① 浸渍纸做 **MV 电路板**；② 浸渍碳纤维网烧制**火箭防热烧蚀瓦**；③ 配芯片塑封料。 |
| **普通环氧树脂 (`Epoxy`)** | 双酚 A + 环氧氯丙烷 + 固化剂 | 粉、板、液体 | 浸玻纤做 **G10 电路板（HV）**；浸高强玻纤/碳纤做**强化环氧树脂板（玻璃钢/机翼/机器外壳/转子）**。 |
| **阻燃环氧树脂 (`FlameRetardantEpoxy`)** | 四溴双酚 A + 环氧氯丙烷 | 粉、液体 | 浸玻纤做 **FR-4 电路板与 EV 芯片封装基板**。 |
| **甲酚醛环氧 (`EpoxyCresolNovolacs` / ECN)** | 甲酚 + 甲醛 + 环氧氯丙烷 | 粉、板 | 与酚醛树脂、炭黑配成**环氧塑封料（EMC）**，封装所有分立电子元件（二极管/晶体管）。 |
| **脂环族环氧 (`epoxycyclohexane_carboxylate`)** | 丁二烯 + 丙烯醛 $\rightarrow$ 环氧化 | 流体 | 配制 PCB 印刷电路板表面的**白油/绿油阻焊涂层**。 |
| **聚氨酯 (`Polyurethane` / PU)** | 苯胺 $\rightarrow$ MDI + 多元醇 | 方块、板、液体 | 泡黄染料做**原版海绵**；做床垫、航天器舱内缓冲衬垫；涂覆尼龙布做宇航服气密层。 |
| **氢化石油树脂 (`HydrogenatedPetroleumResin`)** | 双环戊二烯 + 苯 + 降冰片烯 $\rightarrow$ 加氢 | 粉 | 混石蜡与交联 PS 珠，做成**精密失蜡铸造蜡（铸造燃气轮机单晶叶片）**。 |

## 三、高端工程塑料与氟聚合物终点产物（中后期材料）

| 最终产物 | 上游单体来源 | 需要保留的形态 | 以后接去哪（下游用途） |
|---|---|---|---|
| **聚四氟乙烯 (`PTFE` / 特氟龙)** | 甲烷 + 氯气 + 氢氟酸 $\rightarrow$ 四氟乙烯 | 粉、锭、板、箔、杆、大流体管 | **耐腐蚀化工大机器外壳/管道**、核工业组件、电池/超电隔膜、膨体做成 Gore-Tex 宇航服纤维。 |
| **聚偏氟乙烯 (`PVDF`)** | 二氟一氯乙烷裂解 $\rightarrow$ 偏氟乙烯 | 粉、板 | **电池（镍镉/镍氢）与超级电容电极粘结剂**、**LuV / ZPM 传感器与发射器**。 |
| **全氟磺酸树脂 (`Nafion`)** | 四氟乙烯 + 全氟磺酰氟乙烯基醚 | 粉、板、箔、分散液 | **氢氧燃料电池质子交换膜与催化剂粘结剂**、**全钒液流电池隔膜**。 |
| **聚砜 (`Polysulfone`)** | 双酚 A 钠盐 + 二氯二苯砜 | 粉、板、箔、杆、框架 | **水处理超滤膜（UF 膜）**、**燃料电池框架**、宇航服外层头盔隔热膜。 |
| **聚苯硫醚 (`PolyphenyleneSulfide` / PPS)** | 对二氯苯 + 硫化钠 | 粉、板、箔 | 耐高温耐腐蚀塑料件、高级电缆包覆与过滤材料。 |
| **聚苯醚 (`PolyphenyleneOxide` / PPO)** | 苯酚 + 甲醇 $\rightarrow$ 2,6-二甲基苯酚聚合 | 粉、锭 | 高频绝缘工程塑料件（常与 PS 共混）。 |
| **聚醚酰亚胺 (`Ultem` / PEI)** | 双酚 A + 邻苯二甲酸酐 + 间苯二胺 | 粉、锭 | 高温高强工程塑料结构件（EV/IV 级注塑件）。 |
| **聚酰亚胺 (`Kapton K` / `Kapton E`)** | 均苯四甲酸二酐 + 二氨基二苯醚（及联苯二酐） | 粉、板、箔 | **高级柔性电路板基板**、航天器耐高温绝缘薄膜、超导/低温绝缘层。 |
| **聚醚醚酮 (`PEEK`)** | 对苯二酚 + 二氟二苯甲酮 | 粉、锭 | 顶级耐高温机械零件（IV+ 注塑件）。 |

## 四、合成橡胶终点产物（密封与绝缘线）

SuSy 中橡胶粉需进硫化机（配硫磺 + 氧化锌/氧化镁催化剂）压成**板、环、箔、锭、微型管**：

| 最终产物 | 上游单体来源 | 需要保留的形态 | 以后接去哪（下游用途） |
|---|---|---|---|
| **聚异戊二烯 (`Polyisoprene` $\rightarrow$ `Rubber`)** | 异戊二烯（C5 馏分或异丁烯+甲醛合成） | 混炼粉 $\rightarrow$ 橡胶板/环/箔 | 直接替代天然橡胶（做低压线缆绝缘皮、基础密封圈、传送带）。 |
| **丁苯橡胶 (`StyreneButadieneRubber` / SBR)** | 丁二烯 + 苯乙烯 | 混炼粉 $\rightarrow$ 板/环/箔 | 中期主力合成橡胶：**连铸机密封环**、防毒面具密封、中压线缆外皮。 |
| **丁腈橡胶 (`NitrileRubber` / NBR)** | 丁二烯 + 丙烯腈 | 粉 $\rightarrow$ 板/环/箔 | 耐油气密橡胶：**火箭多方块气密垫片（Aerospace Gasket）**、耐油密封件。 |
| **氯丁橡胶 (`Neoprene`)** | 丁二烯 + 氯气 $\rightarrow$ 氯丁二烯 | 胶乳粉 $\rightarrow$ 板/环/箔 | 与尼龙箔压制成**氯丁橡胶涂覆尼龙布（宇航服气密层）**、耐候密封圈。 |
| **硅橡胶 (`SiliconeRubber`)** | 硅粉 + 氯甲烷 $\rightarrow$ 二甲基二氯硅烷水解 | 粉 $\rightarrow$ 板/环/箔 | **宇航服头盔/胸甲气密环**、高级线缆绝缘层、耐高温垫片。 |
| **氟橡胶 (`Viton` / FKM)** | 偏氟乙烯 + 六氟丙烯 | 粉 $\rightarrow$ 密封环（Ring） | **氢氧燃料电池耐强酸密封圈**、极端腐蚀化工设备密封。 |
| **硬质橡胶 (`Ebonite`)** | 任意生胶 + 大量硫磺 + 炭粉 | 板 | 早期电池外壳与绝缘板。 |

## 六、不进聚合釜的精细石化终点产物（专项功能化学品）

这些产物同样出自石化单体，但不聚合成塑料，而是作为工业耗材留存：

| 最终产物 | 上游单体来源 | 以后接去哪（下游用途） |
|---|---|---|
| **多氯联苯 (`polychlorinated_biphenyl` / PCB)** | 甲苯脱烷基/苯氧化副产**联苯** + 氯气 | ① **64A 变电站大电流能源仓**的高压变压器绝缘油；② **电火花加工机（EDM）**工作液。 |
| **邻苯二甲酸酐 (`dustPhthalicAnhydride`)** | 邻二甲苯（或萘）催化氧化 | ① 制造**双氧水工作载体（2-乙基蒽醌）**；② 合成**酯类润滑油基础油**；③ 环氧树脂固化剂；④ 合成 Ultem。 |
| **磷酸三丁酯 (`tributyl_phosphate` / TBP)** | 1-丁烯 $\rightarrow$ 正丁醇 + 三氯氧磷 | **核工业与稀土萃取剂**：萃取分离铀、钍、钚、铈、锗、镓、铑/铱。 |
| **P204 (`di_two_ethylhexyl_phosphoric_acid`)** | 丙烯 $\rightarrow$ 正丁醛 $\rightarrow$ 异辛醇 | 配合 TBP 萃取**铀与稀土元素**。 |
| **三辛胺 / Aliquat 336** | 乙烯齐聚 $\rightarrow$ 辛醇/癸醇 $\rightarrow$ 叔胺/季铵盐 | **稀土全分离核心萃取剂**（氟碳铈矿/独居石/磷钇矿逐级分离镧、镨、钕、钇、铽）及**钨萃取剂**。 |
| **甲基异丁基酮 (`methyl_isobutyl_ketone` / MIBK)** | 丙酮缩合加氢 | **锆/铪分离**（核级海绵锆必修）与**铌/钽分离**萃取剂。 |
| **聚 $\alpha$-烯烃 (`polyalphaolefin` / PAO) & 聚丁烯** | 1-癸烯 / 丁烯齐聚 | 调配**高级全合成润滑油**与**电火花加工液**。 |
| **MTBE / 异辛烷 / 二茂铁 / MMT** | 异丁烯 / 环戊二烯 | 汽油**抗爆剂（提高辛烷值）**，调配高标号汽油。 |
