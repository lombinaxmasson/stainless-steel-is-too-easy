## 电弧坩埚 / 电弧炉（后期）

- 现实对应：**EAF**（废钢熔化）与 **VAR**（真空电弧重熔），不是把 AOD 电气化。
- 与 AOD 的分工：AOD 只做精炼（吹氧脱碳、氩气稀释），电弧设备只做熔炼，两者不合并。
- 后期门槛建议放在基础设施而不是配方等级：水冷壁（不按材质熔毁，但要冷却水）、石墨电极耗材、大功率 `EU`。
- 待回答：后期的熔融金属给谁用？候选方向：
  - 大型 AOD 转炉的电加热方式；
  - 废钢回收闭环（GT6 的 `scrapGt`）；
  - 连铸 / 铸流线。
- 现状：GT6CE 本体没有电弧炉或电炉，坩埚只吃 `HU`，所以这是真空白。

## 活泼金属的反应器三分法

| 设备 | 对象 | 关键规则 |
|---|---|---|
| AOD 转炉 | 钢 / 不锈钢 | 吹氧脱碳，氩气稀释 |
| 惰性气氛坩埚 / VAR | Ti、Zr | 真空或氩，水冷铜坩埚，电极消耗 |
| 熔盐电解槽 | Al、Mg、Na、Li | 冰晶石类电解质，碳阳极，直流电 |

- **钛**：矿 → 氯化 → `TiCl4` → 镁热还原（Kroll，密闭反应器）→ 海绵钛 → VAR 成锭。
- **铝**：Bayer 法出氧化铝 → Hall–Héroult 冰晶石电解（碳阳极消耗，出 CO2）。
- **不要把 AOD 扩到钛铝**：钛铝的问题不是脱碳，硬扩会绕开真实门槛，与"去掉捷径"的设计哲学相反。
- 可复用：AOD 现在的"开盖投料 + 关盖锁气 + 氩气驻留"交互可以抽成通用能力，给 VAR 用。
- GT6CE 已有材料（只注册了材料，配方链需要再确认）：`Alumina`、`Cryolite`、`SodiumAluminate`、`TitaniumTetrachloride`、`MagnesiumChloride`。
- 建议顺序：先做熔盐电解槽（一台解决 Al / Mg / Na / Li，接 M2 的锂与氯线），再做 VAR 电弧坩埚。量级接近一个新的冶金里程碑，需要单独评估。
