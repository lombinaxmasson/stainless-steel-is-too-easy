# 灵感池

这里收集尚未承诺实施的构想。2026-10-25 先整理已有思路，为讨论准备问题；本轮不新增内容计划卡。工艺名称用于描述游戏设计方向，具体工业路线与参数在开卡前再查证。

| 思路 | 当前归属 | 讨论时的边界 |
|---|---|---|
| 水冷铜 VAR、海绵钛/锆/铪、铝镓与铌钽 | M5 已完成 | 新想法应描述现有实现还缺什么 |

## 讨论一：工厂扩大以后，玩家能获得什么

**大型 AOD 与连续浇铸**。小型 AOD 已有六档炉体；大型设备需要在操作、吞吐量或自动化上提供可感知的变化。候选玩法是集中供熔液、稳定吹炼、连续出坯，让钢厂布局成为一个目标。

待讨论：

- 大型设备主要提高产能，还是解锁连续生产？
- 是沿用现有 HU/KU/氩气接口，还是把预热与精炼分成工段？
- 连铸产出钢坯、板坯还是直接进入现有加工链？新增半成品能带来什么选择？
- 小型 AOD 后期是否继续承担小批量特种钢？

**EAF 与废钢回收**。原有构想将 EAF 用于废钢熔化，VAR 用于活泼金属与高温合金重熔，AOD 用于精炼。水冷壁、石墨电极和大功率 EU 可作为候选基础设施要求；现有 VAR 不能据此认定已经实现冷却水或电极消耗。

待讨论：废钢从哪里持续产生？回收是节省矿石、处理混合金属，还是缩短成熟钢厂的流程？如果没有稳定的废料来源，先记录用途，再决定是否增加设备。

## 讨论二：分离、循环和副产物怎样形成选择

**溶剂与催化剂的维护**。现在已有萃取剂回收与不同损耗率，可以讨论再生工艺能否成为后期升级：减少补料、减少废液，或者让多条产线共用再生站。

待讨论：哪些循环在现有玩法里已经有管理价值？何时值得把损耗折算为补料，何时值得增加可处理的废物流？是否先改善可见性，再考虑新配方？

**伴生资源的分配**。M7 的阳极泥、烟尘与浸出渣为贵金属和稀散元素提供出口。可以围绕现有链讨论：主金属产量与伴生产量是否匹配，玩家是否能按当前短缺选择不同处理路线。

待讨论：哪些副产物需要跨线消化，哪些只需在本线回收？新增分支提供的是收率、能耗还是产物比例的选择？先画物流关系，再判断有没有必要加材料。

## 讨论三：让材料差异进入成品用途

**材料替代与工艺世代**。M9 已规划线缆、基板、半导体和能源部件。脑洞可以集中在“为什么愿意换材料”：耐温、耐酸、电压、寿命、用量或工艺兼容性中，哪些确实能由现有 API 表达？

待讨论：每代材料对应什么明确收益？旧路线是否保留低成本用途？哪些用途只需要改配方，哪些必须新增行为或修改 GT6CE？

**唱片作为能看见、能听见的产线终点**。M8 已有两条工艺方向。可先讨论母盘/压模的复用方式、曲目如何获得、黑胶和 CD-R 是否有不同收集体验。

待讨论：唱片是可反复生产的纪念品、工厂成就奖励，还是承担其他玩法？音乐与美术素材在正式实施时需要从哪里获得？

## 设备分工备忘

保留原有“活泼金属反应器三分法”的设计意图，防止后续把所有高温反应塞给同一台机器：

| 设备/工段 | 主要对象 | 设计边界 |
|---|---|---|
| AOD | 钢、不锈钢 | 吹炼精炼与脱碳；不因温度高就承担钛铝冶炼 |
| VAR / 惰性气氛重熔 | 海绵 Ti/Zr/Hf 与高温合金 | 承接还原后的重熔与合金化；现有 VAR 已实现 |
| 熔盐电解 | Al/Mg/Na/Li 等路线 | 目前复用既有机器配方；是否值得专用设备仍待讨论 |
| EAF（构想） | 废钢等熔化任务 | 先明确原料来源和熔液去向，再评估设备需求 |

## 记录一个新脑洞时

可以只写几句话，不必马上填成计划卡：

- 想让玩家遇到什么问题，获得什么体验？
- 接住现有哪种原料、副产物或闲置材料，产物送去哪里？
- 复用现有机器够不够，新增设备带来什么独有操作？
- 与 M7–M9 的已有规划有什么关系？
- 最大未知是什么，下一次讨论要回答哪个问题？

等用途、边界和可行性清楚后，再决定是否开卡与排期。
