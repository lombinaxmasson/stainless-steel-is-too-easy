# 特种工程塑料：PPS、聚砜、PEEK 与聚酰亚胺（Kapton）详细计划

## 0. 它解决什么

| 塑料 | 原料 | M6 用途 |
|---|---|---|
| **PPS** | 氯苯再氯化得对二氯苯，加 GT6 硫化钠缩聚 | 耐腐蚀泵阀、电子接插件 |
| **聚砜** | 氯苯 + 三氧化硫得二氯二苯砜，加 M3 双酚 A | 超滤膜、医疗器械 |
| **PEEK** | 苯酚 + 双氧水得对苯二酚；氯苯卤素交换得氟苯，加光气得二氟二苯酮 | 航天结构件、高温轴承 |
| **Kapton**（聚酰亚胺） | 混合二甲苯 + 甲醇得均四甲苯，氧化得均酐（PMDA）；对硝基氯苯得二氨基二苯醚 | 柔性电路板基膜、航天器隔热层 |

## 2. 配方（`PolymerRecipes.engineeringPlastics()`）

- **PPS**
  1. 氯苯再氯化（`gt.recipe.mixer`）：`1 × dust FerricChloride`（不消耗）+ `GenLiquid_Chlorobenzene (1000)` + `GenGas_Chlorine (1000)` $\rightarrow$ `1 × dust ParaDichlorobenzene` + `GenGas_HydrochloricAcid (1000)`；32 EU/t，120 ticks
  2. 缩聚（`gt.recipe.mixer`）：`1 × dust ParaDichlorobenzene` + `1 × dust SodiumSulfide` + `DistW (1000)` $\rightarrow$ `1 × dust PolyphenyleneSulfide` + `Saltwater (1000)`
     - 省略 NMP 溶剂。
     - 64 EU/t，240 ticks。
- **聚砜**
  1. 磺化缩合（`gt.recipe.mixer`）：`GenLiquid_Chlorobenzene (2000)` + `三氧化硫 (1000)` $\rightarrow$ `1 × dust Dichlorodiphenylsulfone` + `DistW (1000)`；48 EU/t，200 ticks
  2. 缩聚（`gt.recipe.mixer`）：`1 × dust Dichlorodiphenylsulfone` + `1 × dust BisphenolA` + `2 × dust SodiumHydroxide` $\rightarrow$ `1 × dust Polysulfone` + `Saltwater (2000)`；64 EU/t，240 ticks
- **PEEK**
  1. 苯酚羟基化（`gt.recipe.mixer`）：`1 × dust ZSM5`（不消耗，代替钛硅分子筛）+ `GenLiquid_Phenol (1000)` + `过氧化氢 (1000)` $\rightarrow$ `1 × dust Hydroquinone` + `DistW (1000)`；48 EU/t，200 ticks
  2. 卤素交换（`gt.recipe.mixer`）：`1 × dust PotassiumFluoride` + `GenLiquid_Chlorobenzene (1000)` $\rightarrow$ `GenLiquid_Fluorobenzene (1000)`
     - 氯化钾副产：若 GT6CE 有对应材料（如 `RockSalt`），就占用搅拌机唯一的物品输出槽；否则不出槽。
     - 64 EU/t，200 ticks。
  3. 傅克酰基化（`gt.recipe.mixer`）：`1 × dust FerricChloride`（不消耗）+ `GenLiquid_Fluorobenzene (2000)` + `GenGas_Phosgene (1000)` $\rightarrow$ `1 × dust Difluorobenzophenone` + `GenGas_HydrochloricAcid (2000)`；64 EU/t，200 ticks
  4. 亲核缩聚（`gt.recipe.mixer`）：`1 × dust Difluorobenzophenone` + `1 × dust Hydroquinone` + `1 × dust PotassiumCarbonate` $\rightarrow$ `1 × dust PolyetherEtherKetone` + `CarbonDioxide (1000)` + `DistW (1000)`
     - 省略二苯砜溶剂；氟化钾副产不出槽。
     - 128 EU/t，300 ticks。
- **Kapton**
  1. 二甲苯甲基化（`gt.recipe.mixer`）：`1 × dust ZSM5`（不消耗）+ `GenLiquid_Xylene (1000)` + `GenLiquid_Methanol (2000)` $\rightarrow$ `1 × dust Durene` + `DistW (2000)`；48 EU/t，200 ticks
  2. 均四甲苯氧化（`gt.recipe.mixer`）：`1 × dust VanadiumPentoxide`（不消耗）+ `1 × dust Durene` + `Oxygen (6000)` $\rightarrow$ `1 × dust PyromelliticDianhydride` + `DistW (6000)`；96 EU/t，300 ticks
  3. 二氨基二苯醚（`gt.recipe.mixer`）：`1 × dust Nickel`（不消耗）+ `2 × dust ParaNitrochlorobenzene` + `2 × dust SodiumHydroxide` + `Hydrogen (6000)` $\rightarrow$ `1 × dust Oxydianiline` + `Saltwater (2000)`
     - 碱水解、成醚、加氢三步折成一步。
     - 96 EU/t，300 ticks。
  4. 两步法亚胺化（`gt.recipe.mixer`）：`1 × dust PyromelliticDianhydride` + `1 × dust Oxydianiline` $\rightarrow$ `1 × dust Kapton` + `DistW (2000)`
     - 聚酰胺酸中间体不单独注册。
     - 128 EU/t，400 ticks。
- **成型**：四种塑料都走 `polymerForming`（压板 + 轧箔）。

## 3. 明确不做

- 不做聚苯醚（PPO）、聚醚酰亚胺（PEI）。PPO 需要 2,6-二甲酚，PEI 需要双酚 A 二酐，原料链太长，延后。
- 不做聚醚砜（PES）、PEKK、液晶聚合物（LCP）
- 不做 NMP、二苯砜等高沸点溶剂
- 不做 Kapton 胶带、柔性电路板等成品，留给 M6
