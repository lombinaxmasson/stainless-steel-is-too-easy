# 苯胺、MDI、聚氨酯与氢化石油树脂详细计划

> 计划 slug：`m4/polyurethane-resin`
> 状态：待实现。前置是 [`芳烃氧化与聚碳酸酯`](芳烃氧化光气聚酯与聚碳酸酯详细计划.md)（需要光气）。
> 性质：M4 第二批第二张卡。苯经硝化、加氢、缩合、光气化得 MDI，再和聚醚多元醇反应得聚氨酯，顺带做原版海绵。另外用 M3 的 C5 副产合成氢化石油树脂。

## 0. 它解决什么

- **苯胺**是本卡和第三批芳纶卡的共同起点（芳纶卡走对位 / 间位二胺，但硝化手法相同）。
- **聚氨酯**：
  - MDI 用的光气来自卡 5；
  - 聚醚多元醇吃 GT6 自带的**甘油**（起始剂）和卡 1 的环氧乙烷；
  - 加黄色染料、用二氧化碳发泡，可以做**原版海绵**（路线图里的彩蛋）。
- **氢化石油树脂**：M3 的双环戊二烯、降冰片烯至今只有「热解回环戊二烯」这一个去处。本卡把它们和苯共聚成石油树脂再加氢。成品留给 M6 精密失蜡铸造的蜡模。

## 2. 配方（`PolymerRecipes.polyurethaneResin()`）

- **苯胺**
  1. 混酸硝化（`gt.recipe.mixer`）：`GenLiquid_Benzene (1000)` + `硝酸 (1000)` + `GenLiquid_SulfuricAcid (100)` $\rightarrow$ `GenLiquid_Nitrobenzene (1000)` + `DistW (1000)`
     - 硝酸用 GT6CE 自带的那个，实现时确认字段名。
     - 48 EU/t，160 ticks。
  2. 加氢还原（`gt.recipe.mixer`）：`1 × dust Nickel`（不消耗）+ `GenLiquid_Nitrobenzene (1000)` + `Hydrogen (3000)` $\rightarrow$ `GenLiquid_Aniline (1000)` + `DistW (2000)`；48 EU/t，160 ticks
- **MDI**
  1. 苯胺甲醛缩合（`gt.recipe.mixer`）：`GenLiquid_Aniline (2000)` + `GenGas_Formaldehyde (1000)` + `GenGas_HydrochloricAcid (100)` $\rightarrow$ `1 × dust Methylenedianiline` + `DistW (1000)`；48 EU/t，200 ticks
  2. 光气化（`gt.recipe.mixer`）：`1 × dust Methylenedianiline` + `GenGas_Phosgene (2000)` $\rightarrow$ `GenLiquid_MethyleneDiphenylDiisocyanate (1000)` + `GenGas_HydrochloricAcid (4000)`；64 EU/t，200 ticks
- **聚醚多元醇**（`gt.recipe.mixer`）：`1 × dustTiny PotassiumHydroxide` + `GenLiquid_Glycerol (1000)` + `GenGas_EthyleneOxide (3000)` $\rightarrow$ `GenLiquid_PolyetherPolyol (1000)`；48 EU/t，200 ticks
- **聚氨酯**
  1. 多元醇法（`gt.recipe.mixer`）：`circuit(1)` + `GenLiquid_MethyleneDiphenylDiisocyanate (1000)` + `GenLiquid_PolyetherPolyol (1000)` $\rightarrow$ `2 × dust Polyurethane`；48 EU/t，200 ticks
  2. 乙二醇扩链法（`gt.recipe.mixer`）：`circuit(2)` + `GenLiquid_MethyleneDiphenylDiisocyanate (1000)` + `GenLiquid_EthyleneGlycol (1000)` $\rightarrow$ `1 × dust Polyurethane`；48 EU/t，200 ticks
  3. 成型：走 `polymerForming`。
- **原版海绵**（`gt.recipe.mixer`）：`1 × minecraft:yellow_dye` + `GenLiquid_MethyleneDiphenylDiisocyanate (250)` + `GenLiquid_PolyetherPolyol (250)` + `CarbonDioxide (500)` $\rightarrow$ `1 × minecraft:sponge`；32 EU/t，100 ticks
  - `ChemistryRecipes.item(...)` 只认 GT6 前缀；这里需要直接传原版 `ItemStack`，或给 helper 加一个原版物品重载。
- **石油树脂**
  1. 共聚（`gt.recipe.calciner`）：`1 × dust Norbornene` + `GenLiquid_Dicyclopentadiene (1000)` + `GenLiquid_Benzene (1000)` $\rightarrow$ `3 × dust PetroleumResin`；48 EU/t，240 ticks
  2. 加氢（`gt.recipe.mixer`）：`1 × dust Palladium`（不消耗）+ `1 × dust PetroleumResin` + `Hydrogen (1000)` $\rightarrow$ `1 × dust HydrogenatedPetroleumResin`；48 EU/t，160 ticks

## 3. 明确不做

- 不做 TDI、HDI 等其他异氰酸酯
- 不做环氧丙烷，聚醚多元醇只用环氧乙烷
- 不做己二酸 / 氨纶（己二酸归尼龙 66，不在本里程碑）
- 不做 PU 软泡 / 硬泡之分，不做 PU 方块和 PU 液体形态（留给 M6）
- 不做 C9 石油树脂、萜烯树脂
