## 0. 它解决什么

1. **填补 GT6CE 锆与铪的工业空白**：
   - 在卡 1 移除 `6 Zircon -> 1 Zirconium` 的荒谬离心配方后，锆（`Zirconium`，反应堆燃料棒包壳与茂金属催化剂必需）需要一条正经的工业提炼线。
   - **铪（`Hafnium`）在原版 GT6CE 中完全没有任何生存获取途径**，导致 M1 最高档 **碳化钽铪（$\text{Ta}_4\text{HfC}_5$）AOD 转炉** 与原版 $\text{Ta}_4\text{HfC}_5$ 坩埚在生存模式里断头。
2. **让 M4 的 `MIBK` 萃取剂正式上岗**：
   - 锆和铪是元素周期表里化学性质最接近的「同族双胞胎」，天然锆石总是伴生铪。工业上把粗四氯化锆水解为氯氧化锆溶液后，用 **甲基异丁基酮（`MethylIsobutylKetone` / `MIBK`）** 选择性萃取出铪，水相留下核级纯锆。

## 2. 配方设计（`MetallurgyRecipes.zirconiumHafniumMibk()`）

### 2.1 锆石碳热氯化与四氯化硅回收

1. **锆石沸腾氯化（`gt.recipe.calciner`）**：
   - 对 `carbon` $\in \{\text{`Carbon`}, \text{`CoalCoke`}\}$：
     `1 × dust Zircon` + `4 × dust <carbon>` + `GenGas_Chlorine (4000)` $\rightarrow$ `1 × dust CrudeZirconiumTetrachloride` + `GenLiquid_SiliconTetrachloride (1000)` + `GenGas_CarbonMonoxide (4000)`；96 EU/t，200 ticks。
2. **四氯化硅气相水解回收（`gt.recipe.mixer`）**：
   - `GenLiquid_SiliconTetrachloride (1000)` + `DistW (2000)` $\rightarrow$ `1 × dust SiliconDioxide` + `GenGas_HydrochloricAcid (4000)`；32 EU/t，100 ticks。
   - 说明：副产的二氧化硅与盐酸可全部循环回硅铁/氯碱产线，零废料积压。

### 2.2 水解与 MIBK 溶剂萃取分离锆铪

1. **粗四氯化锆水解（`gt.recipe.mixer`）**：
   - `1 × dust CrudeZirconiumTetrachloride` + `GenLiquid_DeionizedWater (2000)` $\rightarrow$ `GenLiquid_ZirconylChlorideSolution (1000)` + `GenGas_HydrochloricAcid (2000)`；48 EU/t，120 ticks。
2. **MIBK 萃取分相（水相沉锆、有机相富集铪，`gt.recipe.mixer`）**：
   - `GenLiquid_ZirconylChlorideSolution (5000)` + `GenLiquid_MethylIsobutylKetone (1000)` + `GenGas_Ammonia (1000)` $\rightarrow$ `4 × dust Zirconia` + `GenLiquid_HafniumExtract (1000)` + `Dirty_Water (4000)`；64 EU/t，200 ticks。
   - 说明：把「MIBK 萃铪 + 水相纯锆氨沉煅烧」折为一步，直接产出 `4 × dust Zirconia`（二氧化锆）与 `1000 mB HafniumExtract`（富铪有机相），锆铪比设定为游戏体验友好的 **4 : 1**。
3. **富铪有机相反萃与 MIBK 再生（`gt.recipe.centrifuge`）**：
   - `GenLiquid_HafniumExtract (1000)` + `GenLiquid_SulfuricAcid (500)` $\rightarrow$ `1 × dust Hafnia` + `GenLiquid_MethylIsobutylKetone (950)` + `Dirty_Water (500)`；64 EU/t，160 ticks。
   - 说明：单次循环回收 **95% 的 `MIBK`**，只需M4产线补充 5% 的溶剂损耗。

### 2.3 二次氯化与 Kroll 镁热还原制海绵锆 / 海绵铪

1. **二氧化锆氯化（`gt.recipe.calciner`）**：
   - 对 `carbon` $\in \{\text{`Carbon`}, \text{`CoalCoke`}\}$：
     `1 × dust Zirconia` + `2 × dust <carbon>` + `GenGas_Chlorine (4000)` $\rightarrow$ `1 × dust ZirconiumTetrachloride` + `GenGas_CarbonMonoxide (2000)`；64 EU/t，160 ticks。
2. **二氧化铪氯化（`gt.recipe.calciner`）**：
   - 对 `carbon` $\in \{\text{`Carbon`}, \text{`CoalCoke`}\}$：
     `1 × dust Hafnia` + `2 × dust <carbon>` + `GenGas_Chlorine (4000)` $\rightarrow$ `1 × dust HafniumTetrachloride` + `GenGas_CarbonMonoxide (2000)`；64 EU/t，160 ticks。
3. **Kroll 镁热还原制海绵锆（`gt.recipe.calciner`）**：
   - `1 × dust ZirconiumTetrachloride` + `2 × dust Magnesium` + `GenGas_Argon (100)` $\rightarrow$ `1 × dust ZirconiumSponge` + `2 × dust MagnesiumChloride` + `GenGas_Argon (100)`；96 EU/t，240 ticks。
4. **Kroll 镁热还原制海绵铪（`gt.recipe.calciner`）**：
   - `1 × dust HafniumTetrachloride` + `2 × dust Magnesium` + `GenGas_Argon (100)` $\rightarrow$ `1 × dust HafniumSponge` + `2 × dust MagnesiumChloride` + `GenGas_Argon (100)`；120 EU/t，240 ticks。
   - 说明：产出的 `ZirconiumSponge` 与 `HafniumSponge` 送入卡 2 的 `ssite:var_furnace` 重熔为液态 `Zirconium` 与 `Hafnium`；副产 `MagnesiumChloride` 进入镁-氯电解循环。

## 3. 偏差

- **富铪有机相反萃改用搅拌机**：原计划写在 `gt.recipe.centrifuge`，但 GT6CE 离心机只有 1 个流体输入槽，装不下「富铪萃取相 + 硫酸」两路流体；改用 `gt.recipe.mixer`（2 流体入、1 物品出、2 流体出），配方数值不变。

## 4. 明确不做

- 不单独注册硫氰酸铵（`NH4SCN`）络合助剂（折入氨水与 MIBK 萃取步）
- 不做碘化法（Van Arkel–de Boer 晶棒法）二次超纯精炼
