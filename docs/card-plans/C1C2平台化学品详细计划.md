## 0. 它解决什么

GT6CE 有一氧化碳、氢气、氯气、氯化氢、氧气、乙烯，但**没有甲醇、甲醛、乙酸、环氧乙烷、乙二醇、氯乙烯、醋酸乙烯**。M4 的酚醛、聚氨酯、PVC、PVAc/PVA/EVA、PET、MMA、硅橡胶都卡在这几样上。

本卡把它们一次补齐，并尽量吃前面里程碑的产物：

- **孟山都法乙酸**用 M2 卤水提出来的**碘**做助催化剂；
- **平衡氧氯化**：乙烯直接氯化和氧氯化各出一半二氯乙烷，裂解放出的氯化氢正好回到氧氯化，氯不外排；
- **醋提纯冰醋酸**：用 GT6 自带的葡萄醋做早期低收率来源，在甲醇线跑通之前也能拿到乙酸。

- 约定（写进 `PolymerRecipes` 的类注释）：
  1. 编程电路一律写进 `keptInputs`，不消耗；

  3. 量纲沿用 M3：约 `1000 mB` 单体对应 `1 × dust` 聚合物。

## 3. 配方（`PolymerRecipes.cOneCTwoPlatform()`）

- **甲烷蒸汽转化**（`gt.recipe.catalyticcracking`）：`1 × dust Nickel`（不消耗）+ `Methane (1000)` + `Steam (1000)` $\rightarrow$ `GenGas_CarbonMonoxide (1000)` + `Hydrogen (3000)`；64 EU/t，200 ticks
- **甲醇合成**（`gt.recipe.mixer`）：`1 × dust Copper` + `1 × dust Zinc`（均不消耗）+ `GenGas_CarbonMonoxide (1000)` + `Hydrogen (2000)` $\rightarrow$ `GenLiquid_Methanol (1000)`；64 EU/t，200 ticks
- **甲醛（银催化氧化脱氢）**（`gt.recipe.mixer`）：`1 × dust Silver`（不消耗）+ `GenLiquid_Methanol (1000)` + `Oxygen (500)` $\rightarrow$ `GenGas_Formaldehyde (1000)` + `DistW (1000)`；48 EU/t，160 ticks
- **乙酸**
  1. 孟山都法（`gt.recipe.mixer`）：`1 × dust Rhodium`（不消耗）+ `GenLiquid_Methanol (1000)` + `GenGas_CarbonMonoxide (1000)` + `GenGas_Iodine (10)` $\rightarrow$ `GenLiquid_AceticAcid (1000)`；64 EU/t，160 ticks
  2. 乙醛氧化（`gt.recipe.mixer`）：`1 × dust Manganese`（不消耗）+ `GenLiquid_Acetaldehyde (1000)` + `Oxygen (500)` $\rightarrow$ `GenLiquid_AceticAcid (1000)`；32 EU/t，160 ticks
  3. 醋提纯（`gt.recipe.distillery`，早期）：`circuit(3)` + `Vinegar_Grape` / `Vinegar_Apple` / `Vinegar_Cane` / `Vinegar_Rice (1000)` $\rightarrow$ `GenLiquid_AceticAcid (50)` + `DistW (950)`；16 EU/t，100 ticks（四种醋各一条）
- **环氧乙烷**（`gt.recipe.mixer`）：`1 × dust Silver`（不消耗）+ `Ethylene (1000)` + `Oxygen (500)` $\rightarrow$ `GenGas_EthyleneOxide (1000)`；48 EU/t，160 ticks
- **乙二醇**（`gt.recipe.mixer`）：`GenGas_EthyleneOxide (1000)` + `DistW (1000)` $\rightarrow$ `GenLiquid_EthyleneGlycol (1000)`；32 EU/t，120 ticks
- **二氯乙烷**
  1. 直接氯化（`gt.recipe.mixer`）：`1 × dust FerricChloride`（不消耗）+ `Ethylene (1000)` + `GenGas_Chlorine (1000)` $\rightarrow$ `GenLiquid_Dichloroethane (1000)`；32 EU/t，120 ticks
  2. 氧氯化（`gt.recipe.mixer`）：`1 × dust Copper`（不消耗）+ `Ethylene (1000)` + `GenGas_HydrochloricAcid (2000)` + `Oxygen (500)` $\rightarrow$ `GenLiquid_Dichloroethane (1000)` + `DistW (1000)`；48 EU/t，160 ticks
- **二氯乙烷裂解制氯乙烯**（`gt.recipe.calciner`）：`GenLiquid_Dichloroethane (1000)` $\rightarrow$ `GenGas_VinylChloride (1000)` + `GenGas_HydrochloricAcid (1000)`；48 EU/t，160 ticks
- **醋酸乙烯**（`gt.recipe.mixer`）：`1 × dust Palladium`（不消耗）+ `Ethylene (1000)` + `GenLiquid_AceticAcid (1000)` + `Oxygen (500)` $\rightarrow$ `GenLiquid_VinylAcetate (1000)` + `DistW (1000)`；64 EU/t，200 ticks
- **补 M3 卡 4**（改 `PetrochemRecipes.cFourChain()`）：若 `AddonFluids.still("GenLiquid_Ethanol")` 取到的流体和 `BioEthanol` 不同，就给「乙醇铜催化脱氢」和「乙醇乙醛钽催化缩合」各补一行 `GenLiquid_Ethanol` 版本。

## 4. 明确不做

- 不做合成气 / 水煤气变换 / 费托合成（直接用一氧化碳 + 氢气）
- 不做乙炔路线氯乙烯（GT6CE 没有乙炔，也没有电石）
- 不做 Cativa 法（铱催化乙酸）、乙烯酮 / 乙酸酐
- 不做甲醇制烯烃（MTO）和甲醇制汽油（MTG）
