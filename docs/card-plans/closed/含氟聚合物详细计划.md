# 氟化工：PTFE、PVDF、氟橡胶与 Nafion 详细计划

> 计划 slug：`m4/fluoropolymers`
> 状态：关闭。本文件位于 `docs/card-plans/closed/`。前置是 [`C1/C2 平台化学品`](C1C2平台化学品详细计划.md)（需要氯乙烯）和 [`合成橡胶与硫化`](合成橡胶与硫化详细计划.md)（需要氧化镁、炭黑、硫化模型）。

## 0. 它解决什么

- GT6CE 有 `Teflon`（聚四氟乙烯），但**没有合成配方**。本卡走工业路线：

  \[
  \text{CH}_4 \xrightarrow{\text{Cl}_2} \text{CHCl}_3 \xrightarrow{\text{HF, Sb}} \text{R22} \xrightarrow{\text{裂解}} \text{TFE} \rightarrow \text{PTFE}
  \]

- **PVDF**：卡 1 氯乙烯 → 1,1,1-三氯乙烷 → R142b → 偏氟乙烯。这是 M6 锂电正极粘结剂。
- **氟橡胶（Viton）**：偏氟乙烯 + 六氟丙烯共聚，用卡 8 的氧化镁 + 双酚 A 硫化，声明 `metal()` 以得到 O 形圈。
- **Nafion**：四氟乙烯 + 全氟磺酰基乙烯基醚共聚，作为 M6 氯碱膜电解 / 燃料电池的离子膜。
- 全卡副产的大量氯化氢都可回卡 1 氧氯化或卖给 M2。

## 2. 配方（`PolymerRecipes.fluoropolymers()`）

- **TFE / HFP**
  1. 甲烷深度氯化（`gt.recipe.calciner`）：`Methane (1000)` + `GenGas_Chlorine (3000)` $\rightarrow$ `GenLiquid_Chloroform (1000)` + `GenGas_HydrochloricAcid (3000)`；48 EU/t，160 ticks
  2. 锑催化氟化（`gt.recipe.mixer`）：`1 × dust Antimony`（不消耗）+ `GenLiquid_Chloroform (1000)` + `氢氟酸 (2000)` $\rightarrow$ `GenGas_Chlorodifluoromethane (1000)` + `GenGas_HydrochloricAcid (2000)`
     - 氢氟酸用 GT6CE 自带的那个，实现时确认字段名。
     - 64 EU/t，200 ticks。
  3. R22 裂解（`gt.recipe.calciner`）：`GenGas_Chlorodifluoromethane (2000)` $\rightarrow$ `GenGas_Tetrafluoroethylene (1000)` + `GenGas_HydrochloricAcid (2000)`；96 EU/t，200 ticks
  4. TFE 热解（`gt.recipe.calciner`）：`GenGas_Tetrafluoroethylene (3000)` $\rightarrow$ `GenGas_Hexafluoropropylene (2000)`；96 EU/t，200 ticks
- **VDF**
  1. 氯乙烯加成氯化（`gt.recipe.mixer`）：`1 × dust FerricChloride`（不消耗）+ `GenGas_VinylChloride (1000)` + `GenGas_HydrochloricAcid (1000)` + `GenGas_Chlorine (1000)` $\rightarrow$ `GenLiquid_Trichloroethane (1000)` + `GenGas_HydrochloricAcid (1000)`；48 EU/t，160 ticks
  2. 锑催化氟化（`gt.recipe.mixer`）：`1 × dust Antimony`（不消耗）+ `GenLiquid_Trichloroethane (1000)` + `氢氟酸 (2000)` $\rightarrow$ `GenGas_Chlorodifluoroethane (1000)` + `GenGas_HydrochloricAcid (2000)`；64 EU/t，200 ticks
  3. 脱氯化氢（`gt.recipe.calciner`）：`GenGas_Chlorodifluoroethane (1000)` $\rightarrow$ `GenGas_VinylideneFluoride (1000)` + `GenGas_HydrochloricAcid (1000)`；64 EU/t，160 ticks
- **全氟磺酰基乙烯基醚**（`gt.recipe.mixer`）：`GenGas_Tetrafluoroethylene (2000)` + `GenGas_Hexafluoropropylene (1000)` + `三氧化硫 (1000)` $\rightarrow$ `GenLiquid_PerfluorosulfonylVinylEther (1000)`
  - 真实工艺是磺内酯、HFPO 加成、脱羧的多步路线，这里折成一步。
  - 三氧化硫用 GT6CE 自带的那个，实现时确认字段名。
  - 96 EU/t，300 ticks。
- **乳液聚合**（`gt.recipe.mixer`，都用 `1 × dustTiny SodiumPersulfate` 引发、`GenLiquid_DeionizedWater (1000)` 作介质，副产 `DistW (1000)`；四条的输入互相包含，所以必须用电路 1～4 区分）
  1. PTFE：`circuit(1)` + `GenGas_Tetrafluoroethylene (1000)` $\rightarrow$ `1 × dust Teflon`；64 EU/t，200 ticks
  2. PVDF：`circuit(2)` + `GenGas_VinylideneFluoride (1000)` $\rightarrow$ `1 × dust PolyvinylideneFluoride`；64 EU/t，200 ticks
  3. 氟橡胶生胶：`circuit(3)` + `GenGas_VinylideneFluoride (600)` + `GenGas_Hexafluoropropylene (400)` $\rightarrow$ `1 × dust RawViton`；64 EU/t，240 ticks
  4. Nafion：`circuit(4)` + `GenGas_Tetrafluoroethylene (1000)` + `GenLiquid_PerfluorosulfonylVinylEther (1000)` $\rightarrow$ `1 × dust Nafion`；128 EU/t，300 ticks
- **氟橡胶硫化**（`gt.recipe.mixer`）：`1 × dust RawViton` + `1 × dustSmall CarbonBlack` + `1 × dustTiny BisphenolA` + `1 × dust MagnesiumOxide`（不消耗）$\rightarrow$ `1 × ingot Viton`；64 EU/t，240 ticks
- **成型**：PVDF、Nafion 走 `polymerForming`；Teflon 若 GT6 缺板 / 箔来源，只补缺的行。

## 3. 明确不做

- 不做萤石 + 硫酸制氢氟酸（GT6CE 已有氢氟酸来源）
- 不做 FEP、PFA、ETFE 等可熔融氟塑料
- 不做 Nafion 磺酰氟水解转型（直接视为酸型膜）
- 不做氟利昂制冷剂的使用端（M6 制冷再说）
- 不做全氟辛酸（PFOA）表面活性剂
