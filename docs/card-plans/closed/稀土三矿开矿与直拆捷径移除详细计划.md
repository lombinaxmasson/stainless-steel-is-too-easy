# 砍掉稀土/铀矿直拆捷径与三矿浸出分群详细计划

> 计划 slug：`m6/ore-leaching`
> 状态：关闭（2026-10-24）。本文件位于 `docs/card-plans/closed/`。前置是 M5 收官卡 [`铌钽浸出萃取与AOD终极闭环`](铌钽浸出萃取与AOD终极闭环详细计划.md)、M2 [`五级水净化产线`](五级水净化产线详细计划.md)（污泥里的 `dustTiny RareEarth`）与 M4 [`萃取剂与润滑油基础油`](萃取剂与润滑油基础油详细计划.md)（P204 / TBP / Aliquat 336 / 离子交换树脂）。
> 性质：M6 第一张卡。堵住 GT6CE 里「稀土粉进离心机直接甩出 Nd/Y/La/Ce/Cd/Cs」「氟碳铈矿直接电解或坩埚出铈」「沥青铀矿离心/坩埚直接出铀钍铅」这三类捷径，并建立**氟碳铈矿、独居石、磷钇矿**三条差异化开矿线。三条线在最后统一汇入 `MixedRareEarthSolution`，独居石额外副产钍精矿与铀酰液，供第 2～4 张卡使用。

## 0. 它解决什么

1. **GT6CE 的「一键拆元素」漏洞在稀土/核燃料段同样存在**：

   | 原版捷径 | 机器 | 产出 |
   |---|---|---|
   | `RareEarth` 粉（含 `dustTiny` / `dustSmall` / `crushedCentrifuged` 等全部形态） | 离心机 | `8 tiny Nd + 8 tiny Y + 8 tiny La + 8 tiny Ce + 8 tiny Cd + 8 tiny Cs` |
   | `Pitchblende`（沥青铀矿）粉 | 离心机 | `5 Pitchblende -> 3 Uraninite + 1 Th + 1 Pb` |
   | `Monazite`（独居石）粉 | 电解机 | `2 Monazite -> RareEarth + PO4`（独居石直接拆成稀土粉） |
   | `Bastnasite`（氟碳铈矿）粉 | 电解机 | `6 Bastnasite -> Ce + C + F + 3 O`（直接出金属铈） |
   | `Bastnasite` 矿石 | 坩埚熔炼 | 每块矿 **`U/9`** 金属铈（`setSmelting(Ce, U9)`，`U9 = U/9`） |
   | `Uraninite`（晶质铀矿）矿石 | 坩埚熔炼 | 每块矿 **`U/3`** U-238（`setSmelting(U_238, U3)`，`U3 = U/3`） |
   | `Pitchblende` 矿石 | 坩埚熔炼 | 每块矿 **`U/5`** U-238（`setSmelting(U_238, U/5)`） |

2. **补上 GT6CE 完全缺失的稀土工业前段**：氟碳铈矿（轻稀土）、独居石（轻中稀土 + 钍 + 铀）、磷钇矿（重稀土 + 钇）三种矿在 GT6CE 里没有正经的碱/酸分解路线。GT6CE 也**没有 `Xenotime` 这个材料**，需要本卡新注册矿石与矿脉。
3. **让 M4 的萃取剂有明确的输入**：本卡只负责把三种矿变成同一种 `MixedRareEarthSolution`；P204 / Aliquat 336 / TBP / 离子交换树脂的消耗全部留给第 2、4 张卡。

## 2. 移除的原版捷径

|---|---|---|
| `remove_centrifuge_rareearth_dust.json` | `item_inputs: [{"item": "gt6ce:dust_rareearth"}]` | `1 RareEarth -> 8 tiny Nd + 8 tiny Y + 8 tiny La + 8 tiny Ce + 8 tiny Cd + 8 tiny Cs` |
| `remove_centrifuge_rareearth_dustsmall.json` | `gt6ce:dust_small_rareearth` | 同上（小堆形态） |
| `remove_centrifuge_rareearth_dusttiny.json` | `gt6ce:dust_tiny_rareearth` | 同上（微堆形态） |

### 2.2 电解机直拆（`gt.recipe.electrolyzer`）

| 文件名 | 匹配条件 | 被移除的原版行 |
|---|---|---|
| `remove_electrolyzer_monazite.json` | `item_inputs: [{"item": "gt6ce:dust_monazite"}]` | `2 Monazite -> RareEarth + PO4` |
| `remove_electrolyzer_bastnasite.json` | `item_inputs: [{"item": "gt6ce:dust_bastnasite"}]` | `6 Bastnasite -> Ce + C + F + 3 O` |
| `remove_electrolyzer_uraninite.json` | `item_inputs: [{"item": "gt6ce:dust_uraninite"}]` | 仅在本版本确实存在 `Uraninite` 电解行时创建；本卡开工前先用 EMI 确认，不存在就不建该文件。 |

> 电解行带一条 selector 门控输入；`gt6ce:machine_removal` 是子集匹配，规则里只写 `dust_*` 即可命中，不要写 selector。

### 2.3 坩埚直熔（GT6CE 侧前置）

这三条不是 datapack 配方，而是 `MaterialOreProcessing` 里的 `setSmelting(...)`，由 `CrucibleProcess` 直接读取材料字段：

- `Bastnasite -> U/9 Ce`（`setSmelting(Ce, U9)`）
- `Uraninite -> U/3 U-238`（`setSmelting(U_238, U3)`）
- `Pitchblende -> U/5 U-238`（`setSmelting(U_238, U/5)`）

现有 addon API 的 `AddonMaterialContributor.smeltingTargets()` 只允许改**本 addon 自己的材料**（`AddonMaterials.requireOwned`），无法覆盖 GT6CE 内置材料；`gt6ce:machine_removal` 只能删 JEI/EMI 展示行，删不掉 `CrucibleProcess` 的行为。因此需要 GT6CE 侧补一个移除入口（用户是 GT6CE 作者，可直接在 GT6CE 检出里改）：

```text
GT6CE 侧改动（前置）
  core/src/api/java/com/gregtech/gregtech/api/addon/AddonMaterialContributor.java
  core/src/api/java/com/gregtech/gregtech/api/addon/SmeltingTargetRemoval.java        （新）
  core/src/main/java/com/gregtech/gregtech/api/addon/AddonMaterials.java
  core/src/main/java/com/gregtech/gregtech/api/material/GTMaterial.java
```

- `AddonMaterialContributor` 增加 `default List<SmeltingTargetRemoval> smeltingTargetRemovals() { return List.of(); }`；
- `SmeltingTargetRemoval(String material)` 在 `AddonMaterials` 里解析成 `GTMaterial`，清掉 `MaterialProperty.MELTING` 并把 smelting target 复位（或在 `GTMaterial` 加 `clearSmeltingTarget()`，内部把 target 设为自己、amount 设为 0 并移除 `MELTING`）；
- **契约**：移除后该矿石在任意温度下都保持原样——不蒸发、不消失、不变成金属。`CrucibleProcess` 只看到「没有 `MELTING`」，不会走进 smelting 分支。
- ssite 侧在 `SsiteMaterials` 里实现 `smeltingTargetRemovals()`，返回 `Bastnasite`、`Uraninite`、`Pitchblende` 三条。
- 若该 GT6CE 改动本轮不落地：本卡先交付 2.1 / 2.2 的 datapack 移除，坩埚直熔三条记为**已知缺口**，验收里单独列出，不与 datapack 项混在一起勾选。

## 4. 磷钇矿矿石与矿脉（`SsiteMaterials.oreVeins()`）

GT6CE 的 `OreVeinDeclaration` 允许 addon 追加大矿脉，追加在内置矿脉之后，同名同维度会启动失败。`SsiteMaterials` 目前没有覆写 `oreVeins()`，本卡加上：

```java
@Override
public List<OreVeinDeclaration> oreVeins() {
    return List.of(new OreVeinDeclaration(
            "xenotime", OreVeinDeclaration.OVERWORLD,
            0, 30, 20, 3, 16,
            "Xenotime", "Xenotime", "Monazite", "RareEarth"));
}
```

- 维度：主世界；高度 `0..30`（比独居石脉 `20..40` 更深，避免和内置稀土脉抢同一层）。
- 主矿 `Xenotime`、伴生 `Monazite` / `RareEarth`，保持「重稀土矿总与独居石/稀土矿共生」的直觉。
- `.ores()` 不会自动生成矿脉；矿脉只由 `oreVeins()` 生成。
- 矿石/粉尘贴图由 GT6CE 的材质系统自动生成，**本卡没有手工贴图工作**。

## 5. 配方设计（`RareEarthRecipes.oreLeaching()`）

### 5.1 氟碳铈矿：焙烧脱氟 → 盐酸浸出

1. **氧化焙烧（`gt.recipe.calciner`）**：
   `2 × dust Bastnasite + DistW (1000) + Oxygen (500)` $\rightarrow$ `2 × dust BastnasiteCalcine + GenGas_HydrogenFluoride (2000) + CarbonDioxide (2000)`；160 ticks，48 EU/t。
   - 说明：配平按 `2 CeCO3F + H2O + 0.5 O2 -> 2 CeO2 + 2 CO2 + 2 HF`；`HydrogenFluoride` 回到 M5 的氟化工段循环。
2. **盐酸浸出（`gt.recipe.mixer`）**：
   `2 × dust BastnasiteCalcine + GenGas_HydrochloricAcid (6000)` $\rightarrow$ `GenLiquid_MixedRareEarthSolution (2000) + Dirty_Water (3000)`；160 ticks，48 EU/t。
   - 说明：铈在焙烧后以四价存在，本卡不再单独还原；第 2 张卡用氯气氧化沉淀把铈单独拆出来。

### 5.2 独居石：硫酸分解，优先分出钍饼与铀酰液

1. **浓硫酸分解（`gt.recipe.calciner`）**：
   `2 × dust Monazite + GenLiquid_SulfuricAcid (3000)` $\rightarrow$ `1 × dust ThoriumConcentrate + GenLiquid_MixedRareEarthSolution (2000) + GenLiquid_UranylSulfateSolution (500) + Dirty_Water (500)`；200 ticks，64 EU/t。
   - 说明：独居石的钍与铀在酸解后优先进入渣/液；`ThoriumConcentrate` 是第 4 张卡的钍原料，`UranylSulfateSolution` 与沥青铀矿浸出液合并处理。钍饼的水洗折进本行（`Dirty_Water` 同时代表洗液），不再单独出一步。

### 5.3 磷钇矿：碱熔 → 盐酸浸出

1. **碱熔分解（`gt.recipe.calciner`）**：
   `2 × dust Xenotime + 6 × dust SodiumHydroxide + GenGas_HydrochloricAcid (6000)` $\rightarrow$ `GenLiquid_MixedRareEarthSolution (2000) + Dirty_Water (3000)`；240 ticks，64 EU/t。
   - 说明：磷钇矿难溶于酸，工业上先碱熔把 `YPO4` 转成氢氧化物，再用盐酸溶解；配平按 `2 YPO4 + 6 NaOH + 6 HCl -> 2 YCl3 + 6 H2O + 2 Na3PO4`，磷酸钠并入废水，不单独出磷。
   - 若后续想回收磷，可在 M9 把 `Dirty_Water` 换成 `SodiumPhosphate` 溶液，本卡不做。

### 5.4 低品位稀土粉回收（把 M2 污泥的 `dustTiny RareEarth` 接回主线）

1. **稀土粉盐酸浸出（`gt.recipe.mixer`）**：
   `4 × dust RareEarth + GenGas_HydrochloricAcid (6000)` $\rightarrow$ `GenLiquid_MixedRareEarthSolution (1500) + Dirty_Water (1500)`；160 ticks，48 EU/t。
   - 说明：M2 五级水净化的污泥会出 `dustTiny RareEarth`；先在 GT6 的粉尘合并里并成整粉，再走本行。若游戏内没有粉尘合并配方，实施时给 `dustSmall` / `dustTiny` 各补一条按 GT6 权重的换算行。

## 6. 偏差与开工前确认

1. **`Monazite` 的原版捷径是电解机，不是离心机**：总览写作「`Monazite` 离心直拆」，但 `MaterialDecompositionData` 给 `Monazite` 的权限是 `ELECTROLYSER`，本卡按电解机移除，并同步修正总览描述。
2. **`Uraninite` 在本版本没有通用电解行**：它的两条捷径是坩埚熔炼（`U/3` U-238）和选矿链；`remove_electrolyzer_uraninite.json` 只在 EMI 确实查到该行时才建。
3. **`Pitchblende` 同时有离心与坩埚两条捷径**：两条都移除；离心移除后，沥青铀矿的唯一入口是第 4 张卡的氧化酸浸。
4. **`Xenotime` 是新增矿石**：GT6CE 没有磷钇矿材料，也没有对应矿脉；本卡用 `oreByproducts` + `oreVeins` 一起补。若不想动世界生成，备用方案是把 `RareEarth` 矿石当作富钇矿源，但那样三矿结构会缺一角，不推荐。
5. **坩埚直熔需要 GT6CE 侧 API**：见 2.3；这是本卡唯一的跨仓库前置。
6. **零新增机器**：全部落在 `bath` / `calciner` / `mixer` / `centrifuge` / `autoclave` / `electrolyzer` 上，因此**没有新机器贴图**；材料、流体、矿石贴图由 GT6CE 自动生成。

## 7. 明确不做

- 不做稀土分组萃取、单元素分离与金属化（第 2、3 张卡）。
- 不做铀钍的树脂吸附与 TBP 萃取（第 4 张卡）；本卡只产粗液与钍饼。
- 不新增 `Xenotime` 的小矿石（`SmallOreDeclaration`）；只加大矿脉，避免世界生成改动过大。
- 不回收独居石/磷钇矿的磷酸根（并入 `Dirty_Water`）。
- 不改 GT6CE 的选矿链（`crushed` / `washed` / `centrifuged` / `purified`），只移除分解/电解/坩埚直熔。
