## 0. 它解决什么

M7 第 1 卡移除了闪锌矿的一步焙烧（`Roaster: Sphalerite → Zn`）与坩埚直熔，但锌本身还没有真正的产线：

- M7 第 1 卡删掉了闪锌矿的一步焙烧与坩埚直熔，但本移植没有再生成「粉碎纯化闪锌矿 + 硫酸 → 硫酸锌」的纯酸浸 `Bath` 行（运行时用 `whitevitriol` 输出探针核对，`gt.recipe.bath` 中无此行），因此不需要额外的移除规则；
- 镉、铊、铟、锗在本移植里没有矿石入口。镉只剩 M6 已移除的稀土离心行；铟、锗、铊则完全没有来源；
- 总览要求「主金属决定伴生出口」：炼锌时从烟尘和浸出渣里把镉、铊、铟、锗捞出来。

本卡把闪锌矿掰成两条真实路线：**焙烧 → 硫酸浸出 → 电积锌**，以及**烟尘酸浸锌粉置换出镉铊**、**浸出渣盐酸溶解 → TBP 提铟 + 氯化蒸馏水解提锗**。

## 3. 配方设计

### 3.1 闪锌矿焙烧与锌电积

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 闪锌矿沸腾焙烧 | `calciner` | 2 Sphalerite + 3000 O₂ → 2 Zincite + 1 CadmiumThalliumFlueDust + 2000 SO₂ | 240 / 64 |
| 焙砂硫酸浸出 | `mixer` | 1 Zincite + 2000 H₂SO₄ + 1000 蒸馏水 → 3000 `WhiteVitriol`（硫酸锌溶液）+ 1 ZincLeachResidue | 200 / 64 |
| 锌电积 | GT6CE 内置 `electrolyzer` | 电路 1 + 6000 WhiteVitriol + 3000 水 → 1 Zinc + 7000 H₂SO₄ + 1000 O₂ | 64 / 64 |

说明：

- 焙烧把 ZnS 氧化成 ZnO（`Zincite`），硫进 SO₂ 并接回 M7 第 1 卡的硫酸闭环；镉、铊挥发性强，富集在烟尘里单独出料。
- 浸出直接复用 GT6CE 的 `WhiteVitriol` 液体（ZnSO₄）承载硫酸锌溶液，不新造一个同义材质；浸出渣保留铟、锗，交给 3.3。
- 电积沿用 GT6CE 已经存在的 `WhiteVitriol → Zn` 电解行（带电路 1），本卡不重复注册同输入行，避免配方叠层碰撞。2 份闪锌矿 → 2 份焙砂 → 6000 mB 硫酸锌 → 1 份锌，与 GT6CE 原来 `1000 闪锌矿 → 500 锌` 的收率一致。

### 3.2 镉铊烟尘：酸浸与锌粉置换

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 烟尘硫酸浸出 | `mixer` | 2 CadmiumThalliumFlueDust + 2000 H₂SO₄ + 1000 蒸馏水 → 2000 CadmiumThalliumSolution + 1000 Dirty_Water | 160 / 48 |
| 锌粉置换镉 | `mixer` | 2000 CadmiumThalliumSolution + 1 Zinc → 1 Cadmium + 2000 ThalliumSulfateSolution + 1000 WhiteVitriol | 200 / 64 |
| 锌粉置换铊 | `mixer` | 2000 ThalliumSulfateSolution + 1 Zinc → 1 Thallium + 2000 WhiteVitriol | 200 / 64 |

说明：

- 置换反应把锌送进溶液、把镉铊还原成海绵金属：Cd²⁺ + Zn → Cd + Zn²⁺，Tl⁺ + Zn → Tl + Zn²⁺。先置换更易还原的镉，再置换铊；生成的硫酸锌液回到锌线，形成小闭环。
- 搅拌机只有 1 个物品输出槽，所以镉、铊分两步置换，而不是一份配方同时出两种金属。
- 4 份闪锌矿 → 2 份焙砂 → 1 份锌；同一批烟尘置换要消耗 2 份锌，因此**要镉铊就基本放弃这批锌**，这是本卡的资源取舍。

### 3.3 锌浸出渣：TBP 提铟与氯化蒸馏提锗

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 浸出渣盐酸溶解 | `mixer` | 4 ZincLeachResidue + 4000 HCl → 2000 IndiumChlorideSolution + 4000 CrudeGermaniumTetrachloride + 1 Hematite | 240 / 64 |
| 四氯化锗蒸馏 | `distillery` | 电路 1 + 4000 CrudeGermaniumTetrachloride → 3000 GermaniumTetrachloride + 1000 Dirty_Water | 240 / 64 |
| 四氯化锗水解 | `mixer` | 2000 GermaniumTetrachloride + 4000 超纯水 → 1 GermaniumDioxide + 4000 HCl | 200 / 64 |
| 二氧化锗氢还原 | `calciner` | 1 GermaniumDioxide + 2000 H₂ → 1 Germanium + 2000 蒸馏水 | 200 / 64 |
| TBP 萃铟 | `mixer` | 2000 IndiumChlorideSolution + 1000 TBP → 1000 TbpIndiumExtract + 2000 Dirty_Water | 160 / 64 |
| 铟反萃 | `mixer` | 1000 TbpIndiumExtract + 1000 H₂SO₄ → 2000 IndiumSulfateSolution + 950 TBP | 160 / 48 |
| 锌粉置换铟 | `mixer` | 2000 IndiumSulfateSolution + 1 Zinc → 1 Indium + 2000 WhiteVitriol | 200 / 64 |

说明：

- 铟、锗都在锌浸出渣里。盐酸溶解把两者一起转入液相：锗以 GeCl₄ 形式挥发，铟留在氯化铟溶液里。
- 四氯化锗用 `distillery` 按电路 1 蒸馏提纯（蒸馏器只有 1 个流体输入槽，用 `circuit(1)` + `keep(0)` 固定顺序），水解成 GeO₂ 后用氢还原成半导体级锗粉。
- 铟用 M4 的 `TBP` 从盐酸体系萃取，硫酸反萃回收 95% 有机相，再用锌粉置换出海绵铟；置换副产的硫酸锌液同样回到锌线。
- 4 份浸出渣（8 份闪锌矿的产量）→ 1 铟 + 1 锗，保持稀散金属「少量伴生」的定位。

## 4. 与总览/上游设计的偏差（开工前确认）

1. **锌溶液复用 `WhiteVitriol`**：总览写「焙砂硫酸浸出电积」，没有指定中间材质名。GT6CE 已有 `WhiteVitriol`（ZnSO₄）液体与它的电解行，本卡直接复用，不再注册 `ZincSulfateSolution` 同义材质。
2. **电积行不重写**：GT6CE 内置的 `WhiteVitriol + 水 → Zn + H₂SO₄ + O₂`（电路 1）保留为本卡的锌电积步骤；本卡只补前段焙烧与浸出，避免同输入配方碰撞。
3. **闪锌矿纯酸浸 Bath 行不存在**：`SharedPurifiedAcidRows` 本该为 `Sphalerite` 生成「粉碎纯化矿 + 硫酸 → WhiteVitriol + 氢气」的 Bath 行，但本移植里 `WhiteVitriol` 的流体相绑定没有通过它的严格校验，运行时没有任何 Bath 行输出 `whitevitriol`。因此本卡**不写移除规则**（写了也匹配不到东西），闪锌矿的旧捷径实际上只剩第 1 卡已经移除的一步焙烧与坩埚直熔。`Smithsonite`（碳酸锌）如果生成纯酸浸行则符合湿法冶金，保留不动。
4. **铊不单独走氯化沉淀**：总览要求「酸浸锌粉置换得镉与铊」，本卡让镉铊在同一份溶液里被锌粉一起置换，不再单开 TlCl 沉淀线。
5. **四氯化锗用液体承载**：GeCl₄ 在室温是液体，注册为 `.liquid()`；蒸馏与水解都在流体层完成，不新造气体形态。
6. **镉铊置换消耗锌**：这是有意的资源取舍，避免闪锌矿同时白送锌、镉、铊三种金属。
