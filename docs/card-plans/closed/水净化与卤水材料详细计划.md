## 0. 它解决什么

GT6CE 原版已有原水（`Water`、`River_Water`、`Dirty_Water`、`Swampwater`、`Stagnant_Water`）、污水与污泥（`Sewage`、`Sludge`）、蒸馏水（`DistW`）、海水/盐水/卤水（`Ocean`、`Saltwater`、`Brine`）以及溴、碘、氯、沸石、石英砂、生石灰、石膏、氯化镁、氯化锂等基础材料，但缺少：

1. **五级递进的净化水体流体**（澄清水 $\rightarrow$ 软化水 $\rightarrow$ 去离子水 $\rightarrow$ 反渗透水 $\rightarrow$ 电子级超纯水）与杀菌脱碳用的**臭氧 (`Ozone`)**、絮凝剂**明矾 (`Alum`)**、反渗透膜材料**醋酸纤维素 (`CelluloseAcetate` 粉/板/箔)**；
2. **卤水梯级分离中间体**（熟石灰 `CalciumHydroxide`、氢氧化镁 `MagnesiumHydroxide`、脱镁钙净化卤水 `DecalcifiedBrine`、粗溴蒸汽 `CrudeBromine`、富锂母液 `LithiumRichBrine`、碳酸锂 `LithiumCarbonate`）。

在 GT6CE Addon SDK 中，`MaterialDeclaration.Builder` 调用 `.liquid()` 或 `.gas()` 会自动在 `FluidCatalog` 注册 `GenLiquid_<Name>` / `GenGas_<Name>` 流体并绑定 `material.gt6ce.<小写材料名>` 译名；调用 `.dust()` 的附属材料可在 `forms()` 中显式请求 `plate` 与 `foil`（`AddonMaterials.explicitPlateOrFoil` 特例），无需 `metal()` 即可生成板和滤膜箔。

## 1. 行为

- 在 `SsiteMaterials.materials()` 中追加 14 种 M2 材料声明：
  - **水净化阶梯流体（5 种，纯 `.liquid()`）**：
    1. `ClarifiedWater`（絮凝澄清水 / Clarified Water）：`color(0x5B9BD5)`、`chemicalFormula("H2O")`、`meltingPointKelvin(273)`、`boilingPointKelvin(373)`、`density(1.0F)`、`liquid()`。
    2. `DemineralizedWater`（软化脱矿水 / Demineralized Water）：`color(0x6FB1E8)`、`chemicalFormula("H2O")`、`meltingPointKelvin(273)`、`boilingPointKelvin(373)`、`density(1.0F)`、`liquid()`。
    3. `DeionizedWater`（去离子水 / Deionized Water）：`color(0x88C6F5)`、`chemicalFormula("H2O")`、`meltingPointKelvin(273)`、`boilingPointKelvin(373)`、`density(1.0F)`、`liquid()`。
    4. `FilteredWater`（反渗透纯水 / Filtered Water）：`color(0xA6DAFF)`、`chemicalFormula("H2O")`、`meltingPointKelvin(273)`、`boilingPointKelvin(373)`、`density(1.0F)`、`liquid()`。
    5. `UltrapureWater`（电子级超纯水 / Ultrapure Water）：`color(0xC8ECFF)`、`chemicalFormula("H2O")`、`meltingPointKelvin(273)`、`boilingPointKelvin(373)`、`density(1.0F)`、`liquid()`。
  - **水处理药剂与膜材料（3 种）**：
    6. `Alum`（明矾 / Potassium Alum）：`color(0xE8EEF2)`、`chemicalFormula("KAl(SO4)2·12H2O")`、`meltingPointKelvin(365)`、`boilingPointKelvin(473)`、`density(1.72F)`、`dust()`。
    7. `CelluloseAcetate`（醋酸纤维素 / Cellulose Acetate）：`color(0xF5F5EB)`、`chemicalFormula("C6H7O2(OH)(OAc)2")`、`meltingPointKelvin(503)`、`boilingPointKelvin(650)`、`density(1.30F)`、`dust()`。
    8. `Ozone`（臭氧 / Ozone）：`color(0x70B8FF)`、`chemicalFormula("O3")`、`meltingPointKelvin(81)`、`boilingPointKelvin(161)`、`density(0.00214F)`、`gas()`。
  - **卤水综合利用材料与中间流体（6 种）**：
    9. `CalciumHydroxide`（熟石灰 / Calcium Hydroxide）：`color(0xF2EFE9)`、`chemicalFormula("Ca(OH)2")`、`meltingPointKelvin(853)`、`boilingPointKelvin(2800)`、`density(2.21F)`、`dust()`。
    10. `MagnesiumHydroxide`（氢氧化镁 / Magnesium Hydroxide）：`color(0xF5F0FA)`、`chemicalFormula("Mg(OH)2")`、`meltingPointKelvin(623)`、`boilingPointKelvin(2800)`、`density(2.34F)`、`dust()`。
    11. `DecalcifiedBrine`（除镁钙净化卤水 / Decalcified Brine）：`color(0xB8E0D2)`、`chemicalFormula("NaCl·Br·Li")`、`meltingPointKelvin(255)`、`boilingPointKelvin(380)`、`density(1.18F)`、`liquid()`。
    12. `CrudeBromine`（粗溴蒸汽 / Crude Bromine Vapor）：`color(0x7A2018)`、`chemicalFormula("Br2·Cl2·H2O")`、`meltingPointKelvin(265)`、`boilingPointKelvin(340)`、`density(0.0035F)`、`gas()`。
    13. `LithiumRichBrine`（富锂母液 / Lithium-Rich Brine）：`color(0xD4C8F0)`、`chemicalFormula("LiCl·NaCl")`、`meltingPointKelvin(250)`、`boilingPointKelvin(385)`、`density(1.22F)`、`liquid()`。
    14. `LithiumCarbonate`（碳酸锂 / Lithium Carbonate）：`color(0xF0EDF8)`、`chemicalFormula("Li2CO3")`、`meltingPointKelvin(996)`、`boilingPointKelvin(1583)`、`density(2.11F)`、`dust()`。
- 在 `SsiteMaterials.forms()` 中为 `CelluloseAcetate` 追加板与箔形态请求：
  - `new MaterialFormRequest("plate", "CelluloseAcetate")`
  - `new MaterialFormRequest("foil", "CelluloseAcetate")`（作为 4 级反渗透纯水的 RO 滤膜组件 `gt6ce:foil_cellulose_acetate`）
- 在 `common/src/main/resources/assets/gt6ce/lang/en_us.json` 与 `zh_cn.json` 中补齐上述 14 个 `material.gt6ce.<小写材料名>` 键。

## 2. 明确不做

- 不重复注册 GT6CE 已经内置的材料或流体（如 `Ocean`、`Saltwater`、`Brine`、`DistW`、`Sewage`、`Sludge`、`Bromine`、`Iodine`、`Chlorine`、`Zeolite`、`QuartzSand`、`Quicklime`、`Gypsum`、`Calcite`、`MagnesiumChloride`、`LithiumChloride`）
- 不给 `CelluloseAcetate` 声明 `metal()`（避免生成无意义的醋酸纤维素锭、齿轮、螺丝与熔融金属流体）
- 不在这张卡里写机器配方（留给第 2、3 张卡）
