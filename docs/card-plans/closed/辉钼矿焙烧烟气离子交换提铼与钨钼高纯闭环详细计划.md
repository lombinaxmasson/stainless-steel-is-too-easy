## 0. 它解决什么

M7 第 1 卡删掉了 `Molybdenite` 的一步焙烧（`Roaster: Molybdenite → Mo`）与坩埚直熔，但钼、铼都没有替代产线：

- **钼**：本移植里辉钼矿焙烧被删后没有任何钼来源，而 M3 的丙烯腈与丙烯酸已经把 `Molybdenum` 当作催化剂消耗；
- **铼**：GT6CE 没有任何铼配方，M9 要做的含铼单晶高温合金没有核心元素；
- 钨在 M5 已经由白钨矿/黑钨矿闭环，本卡补上高纯钼后，「钨钼」两端都齐了。

本卡按真实的钼焙烧—铼回收工艺：**辉钼矿氧化焙烧 → 三氧化钼 + 含铼烟气 → 烟气水洗 → 弱碱性阴离子交换树脂吸附 → 氨水洗脱结晶 → 高铼酸铵 → 氢还原得铼**；三氧化钼自身走**氨溶 → 钼酸铵溶液 → 氢还原**得高纯钼。

## 3. 配方设计

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 辉钼矿氧化焙烧 | `calciner` | 2 Molybdenite + 7000 O₂ → 2 MolybdenumTrioxide + 1500 SO₂ + 1000 RheniumFlueGas | 240 / 64 |
| 含铼烟气水洗 | `mixer` | 1000 RheniumFlueGas + 2000 蒸馏水 → 2000 RheniumScrubSolution | 160 / 48 |
| 阴离子树脂吸附 | `bath` | 1 AnionExchangeResin + 2000 RheniumScrubSolution → 1 RheniumLoadedResin + 2000 Dirty_Water | 160 / 32 |
| 氨水洗脱结晶 | `bath` | 1 RheniumLoadedResin + 2000 NH₃ → 1 AmmoniumPerrhenate + 1 AnionExchangeResin + 1000 Dirty_Water | 160 / 32 |
| 高铼酸铵氢还原 | `calciner` | 2 AmmoniumPerrhenate + 4000 H₂ → 2 Rhenium + 2000 NH₃ + 4000 蒸馏水 | 200 / 64 |
| 三氧化钼氨溶 | `mixer` | 2 MolybdenumTrioxide + 2000 NH₃ + 2000 蒸馏水 → 2000 AmmoniumMolybdateSolution | 160 / 48 |
| 钼酸铵氢还原 | `calciner` | 2000 AmmoniumMolybdateSolution + 3000 H₂ → 1 Molybdenum + 2000 NH₃ + 4000 蒸馏水 | 200 / 64 |

说明：

- **焙烧**：MoS₂ + 7/2 O₂ → MoO₃ + 2 SO₂；矿石里的铼以 Re₂O₇ 挥发进烟气，和 SO₂ 一起离开焙烧炉。`calciner` 有 3 个流体输出槽，正好分开放两种气体。
- **水洗**：Re₂O₇ 溶于水生成高铼酸（HReO₄），洗涤液进离子交换。
- **树脂吸附与洗脱**：M4 第 13 卡用氨水在氯甲基化聚苯乙烯上做出来的 `AnionExchangeResin` 就是弱碱性阴离子树脂（伯胺/仲胺基），对 ReO₄⁻ 选择性高；吸附后树脂变成载铼树脂，氨水把铼洗脱成高铼酸铵并让树脂再生。两行 `bath` 一进一出，树脂净零消耗。
- **氢还原**：NH₄ReO₄ + 2 H₂ → Re + NH₃ + 4 H₂O（按游戏比例配平到 2:4:2:2:4）；钼酸铵同样氢还原出钼，氨与水回收。
- 2 份辉钼矿 → 1 份高纯钼；4 份辉钼矿的烟气 → 1 份铼，保持铼「超合金核心元素」的稀缺定位。

## 4. 与总览/上游设计的偏差（开工前确认）

1. **复用 `AnionExchangeResin`**：总览写「弱碱性阴离子交换树脂」，M4 第 13 卡的 `AnionExchangeResin` 正是氯甲基化聚苯乙烯 + 氨水做出来的弱碱性树脂（不是季铵强碱树脂），本卡直接复用，不新造树脂材质。
2. **吸附与洗脱走 `bath`**：离子交换是常温柱式操作，`mixer` 只有 1 个物品输出槽、放不下「高铼酸铵 + 再生树脂」两样东西；`bath` 有 6 个物品输出槽，正合适。
3. **高铼酸铵在洗脱行直接结晶**：总览写「氨水洗脱结晶得高铼酸铵」，本卡把洗脱与结晶合并成一行，不新增结晶中间体。
4. **不新增钨钼合金**：M5 已经闭环钨，本卡只把钼提纯到可用的高纯粉；目前没有任何配方消耗 W-Mo 合金，按「不为假设需求提前造材质」的约定不新增。
5. **不新增移除规则**：辉钼矿的一步焙烧与坩埚直熔已在 M7 第 1 卡删除，本移植也没有辉钼矿的纯酸浸 Bath 行；本卡只补正线。
