## 0. 它解决什么

丁二烯是 M4 合成橡胶（丁苯、丁腈、氯丁）的核心单体，异丁烯和 1-丁烯是丁基胶与线性低密度聚乙烯的共聚单体。本卡让丁二烯有三条来源，玩家可以按自己手里有什么来选：

- **裂解碳四抽提**：石脑油裂解的副产，量小但白送；溶剂沿用第 3 张卡的糠醛（历史上 Phillips 法正是用糠醛萃取精馏丁二烯）；
- **丁烷/丁烯脱氢**：GT6 内置的 `Butane` 和本卡拆出来的正丁烯都能脱氢成丁二烯；
- **乙醇两步法（Ostromislensky）**：乙醇脱氢成乙醛，再与乙醇在钽催化剂上缩合脱水。这是不碰石油的彩蛋路线。

丁二烯到手后顺手做**环丁砜**：丁二烯 + 二氧化硫 + 氢气，作为比糠醛损耗更低的第二代芳烃抽提溶剂，反哺第 3 张卡。

## 1. 行为

在 `PetrochemRecipes` 中新增 `cFourChain()`：

- **第一步：裂解碳四糠醛萃取精馏丁二烯**（`gt.recipe.mixer`）
  - 输入：`GenGas_CFourFraction (1000 mB)` + `GenLiquid_Furfural (50 mB)`
  - 输出：`GenGas_Butadiene (400 mB)` + `GenGas_Butene (600 mB)`
  - 耗能与时长：32 EU/t，120 ticks
- **第二步：混合丁烯三分**（`gt.recipe.distillationtower`）
  - 输入：`GenGas_Butene (1000 mB)`
  - 输出：`GenGas_Isobutylene (500)` + `GenGas_OneButene (300)` + `GenGas_TwoButene (200)`
  - 耗能与时长：48 EU/t，160 ticks
- **第三步：脱氢制烯烃与丁二烯**
  1. **丁烷铬系催化脱氢**（`gt.recipe.catalyticcracking`）：`1 × dust Chromium`（不消耗）+ `Butane (1000)` $\rightarrow$ `GenGas_Butene (900)` + `Hydrogen (900)`；48 EU/t，160 ticks
  2. **1-丁烯氧化脱氢**（`gt.recipe.mixer`）：`1 × dust Molybdenum`（不消耗）+ `GenGas_OneButene (1000)` + `Oxygen (500)` $\rightarrow$ `GenGas_Butadiene (900)` + `DistW (1000)`；64 EU/t，160 ticks
  3. **2-丁烯氧化脱氢**（`gt.recipe.mixer`）：同上，把 `GenGas_OneButene` 换成 `GenGas_TwoButene`
- **第四步：乙醇两步法丁二烯（Ostromislensky）**
  1. **乙醇铜催化脱氢制乙醛**（`gt.recipe.catalyticcracking`）：`1 × dust Copper`（不消耗）+ `BioEthanol (1000)` $\rightarrow$ `GenLiquid_Acetaldehyde (900)` + `Hydrogen (900)`；32 EU/t，120 ticks
  2. **乙醇乙醛钽催化缩合**（`gt.recipe.mixer`）：`1 × dust Tantalum`（不消耗）+ `BioEthanol (1000)` + `GenLiquid_Acetaldehyde (1000)` $\rightarrow$ `GenGas_Butadiene (800)` + `DistW (1600)`；48 EU/t，200 ticks
  3. 若 GT6CE 另有 `GenLiquid_Ethanol` 字段，上面两条对它各再注册一份（实现时以 `AddonFluids.still` 能取到的字段为准）
- **第五步：环丁砜合成**（`gt.recipe.mixer`）
  - 输入：`1 × dust Nickel`（不消耗）+ `GenGas_Butadiene (1000)` + `GenGas_SulfurDioxide (1000)` + `Hydrogen (2000)`
  - 输出：`GenLiquid_Sulfolane (1000 mB)`
  - 耗能与时长：48 EU/t，200 ticks
- **第六步：环丁砜芳烃萃取与汽提**（第二代溶剂，接第 3 张卡的 BTEX 精馏）
  1. 裂解汽油萃取（`gt.recipe.mixer`）：`GenLiquid_PyrolysisGasoline (2000)` + `GenLiquid_Sulfolane (1000)` $\rightarrow$ `GenLiquid_SulfolaneExtract (2300)` + `GenLiquid_Raffinate (700)`；48 EU/t，160 ticks
  2. 重整油萃取（`gt.recipe.mixer`）：`GenLiquid_Reformate (2000)` + `GenLiquid_Sulfolane (1000)` $\rightarrow$ `GenLiquid_SulfolaneExtract (2500)` + `GenLiquid_Raffinate (500)`；48 EU/t，160 ticks
  3. 汽提（`gt.recipe.distillery`）：`circuit(1)` + `GenLiquid_SulfolaneExtract (2300)` $\rightarrow$ `GenLiquid_Sulfolane (990)` + `GenLiquid_BTEX (1300)`（每批损耗 10 mB，约 1%）；32 EU/t，120 ticks

## 2. 明确不做

- 不做 MTBE 醚化法分离异丁烯与 1-丁烯（直接蒸馏三分，游戏性优先）
- 不做 NMP / DMF / 乙腈萃取丁二烯
- 不做丁二烯与异丁烯的下游聚合（M4 橡胶卡与聚烯烃卡）
- 不做 Lebedev 一步法（与两步法产物相同，只保留需要钽催化剂的两步法）
