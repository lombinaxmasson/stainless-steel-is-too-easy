## 0. 它解决什么

**萃取剂**：

| 萃取剂 | 路线 | 后续用途 |
|---|---|---|
| MIBK | M3 丙酮在树脂 + 钯上一步缩合加氢 | 锆铪分离、铌钽分离 |
| TBP | 三氯氧磷 + 卡 2 正丁醇 | 铀钍、锆铪 |
| P204 | 三氯氧磷 + 卡 2 的 2-乙基己醇 | 稀土分离 |
| Aliquat 336 | Ziegler 法辛醇 → 三辛胺 → 卡 8 一氯甲烷季铵化 | 钒钼钨 |

**合成润滑油**：

- 乙烯在铝上齐聚得 α-烯烃混合物，精馏切出 1-辛烯 / 1-癸烯，同时回收 M3 已有的 1-丁烯；
- 1-癸烯齐聚加氢得 **PAO**；
- M3 的异丁烯在 Lewis 酸上聚合得**聚异丁烯**（粘度指数改进剂 / 气密层）。

## 2. 配方（`PolymerRecipes.extractantsLubricants()`）

- **MIBK 一步法**（`gt.recipe.mixer`）：`1 × dust CationExchangeResin` + `1 × dust Palladium`（均不消耗）+ `GenLiquid_Acetone (2000)` + `Hydrogen (1000)` $\rightarrow$ `GenLiquid_MethylIsobutylKetone (1000)` + `DistW (1000)`；48 EU/t，200 ticks
- **磷系萃取剂**
  1. 三氯氧磷（`gt.recipe.mixer`）：`1 × dust Phosphorus` + `GenGas_Chlorine (3000)` + `Oxygen (500)` $\rightarrow$ `GenLiquid_PhosphorylChloride (1000)`；48 EU/t，160 ticks
  2. TBP（`gt.recipe.mixer`）：`GenLiquid_PhosphorylChloride (1000)` + `GenLiquid_Butanol (3000)` $\rightarrow$ `GenLiquid_TributylPhosphate (1000)` + `GenGas_HydrochloricAcid (3000)`；48 EU/t，200 ticks
  3. P204（`gt.recipe.mixer`）：`GenLiquid_PhosphorylChloride (1000)` + `GenLiquid_TwoEthylhexanol (2000)` + `DistW (1000)` $\rightarrow$ `GenLiquid_DiethylhexylPhosphoricAcid (1000)` + `GenGas_HydrochloricAcid (3000)`；48 EU/t，200 ticks
- **胺类萃取剂**
  1. Ziegler 法辛醇（`gt.recipe.mixer`）：`1 × dust Aluminium`（不消耗）+ `Ethylene (4000)` + `Oxygen (500)` + `DistW (1000)` $\rightarrow$ `GenLiquid_Octanol (1000)`
     - 三乙基铝链增长、氧化、水解三步折成一步。
     - 64 EU/t，240 ticks。
  2. 三辛胺（`gt.recipe.mixer`）：`1 × dust Nickel`（不消耗）+ `GenLiquid_Octanol (3000)` + `GenGas_Ammonia (1000)` $\rightarrow$ `GenLiquid_Trioctylamine (1000)` + `DistW (3000)`；64 EU/t，240 ticks
  3. 季铵化（`gt.recipe.mixer`）：`GenLiquid_Trioctylamine (1000)` + `GenGas_Chloromethane (1000)` $\rightarrow$ `GenLiquid_Aliquat (1000)`；48 EU/t，160 ticks
- **合成润滑油**
  1. 乙烯齐聚（`gt.recipe.mixer`）：`circuit(1)` + `1 × dust Aluminium`（不消耗）+ `Ethylene (4000)` $\rightarrow$ `GenLiquid_AlphaOlefins (1000)`；64 EU/t，240 ticks
  2. α-烯烃精馏（`gt.recipe.distillationtower`）：`GenLiquid_AlphaOlefins (1000)` $\rightarrow$ `GenGas_OneButene (250)` + `GenLiquid_OneOctene (300)` + `GenLiquid_OneDecene (250)` + `Fuel (200)`
     - 1-己烯和更重的组分并进燃油。
     - 64 EU/t，160 ticks。
  3. PAO（`gt.recipe.mixer`）：`1 × dust SolidPhosphoricAcid` + `1 × dust Nickel`（均不消耗）+ `GenLiquid_OneDecene (3000)` + `Hydrogen (1000)` $\rightarrow$ `GenLiquid_Polyalphaolefin (1000)`；64 EU/t，240 ticks
  4. 聚异丁烯（`gt.recipe.mixer`）：`1 × dust FerricChloride`（不消耗）+ `GenGas_Isobutylene (1000)` $\rightarrow$ `GenLiquid_Polyisobutylene (1000)`；48 EU/t，200 ticks

## 3. 明确不做

- 不做萃取剂的使用端（萃取塔、混合澄清槽），留给后续湿法冶金里程碑
- 不做 P507、Cyanex、LIX 等其他萃取剂
- 不做 1-辛烯 / 1-己烯共聚 LLDPE
- 不做润滑油调和、润滑脂，不做 PAO 作为 GT6 润滑剂的替代配方（留给 M6）
- 不做丁基胶（聚异丁烯只做液体）
