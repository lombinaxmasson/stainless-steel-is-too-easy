## 0. 它解决什么

1. **原版 0 电耗敞口化学浴产钛粉**：
   - GT6CE 的 `GTChemGen` 第 193–194 行在 `gt.recipe.bath`（**0 EU/t**）里直接用 `Mg / Na + TiCl4 -> dustTitanium + MgCl2 / NaCl`，产出的还是能在普通坩埚里直接化掉的纯钛粉。
   - 同时 `GTChemGen` 第 176–191 行在 `gt.recipe.burnmixer` 里要求输入怪异的**熔融方解石流体（`m:CaCO3`）**并一步直接产出纯 `TiCl4`，跳过了粗四氯化钛除钒精馏。
2. **钒（`Vanadium`）与五氧化二钒（`V2O5`）缺乏工业主来源**：
   - M4 的硫酸接触法、邻二甲苯/均四甲苯氧化、环己酮氧化都用到了 `VanadiumPentoxide` 催化剂，M1 也有钒钢，但原版除了筛黑砂/磁铁矿砂极小概率掉落外没有正经提钒产线。
   - 现实中钛铁矿/金红石沸腾氯化得到的粗 $\text{TiCl}_4$ 含有黄色的**三氯氧钒（$\text{VOCl}_3$）**杂质，必须精馏脱除，这也是工业提钒的重要来源。
3. **建立完整的「镁-氯大循环」**：
   - $\text{TiCl}_4 + 2\text{Mg} \rightarrow \text{Ti (海绵钛)} + 2\text{MgCl}_2$，副产的无水氯化镁直接进电解机拆回 `Magnesium` + `Chlorine`（还可由 M2 卤水提镁线补充损耗），形成严丝合缝的工业自循环。

## 3. 配方设计（`MetallurgyRecipes.titaniumVanadiumKroll()`）

### 3.1 金红石 / 钛铁矿沸腾氯化与氯化铁氯循环

1. **金红石碳热氯化（`gt.recipe.calciner`）**：
   - 对 `carbon` $\in \{\text{`Carbon`}, \text{`CoalCoke`}\}$：
     `1 × dust Rutile` + `2 × dust <carbon>` + `GenGas_Chlorine (4000)` $\rightarrow$ `GenLiquid_CrudeTitaniumTetrachloride (1000)` + `GenGas_CarbonMonoxide (2000)`；64 EU/t，160 ticks。
2. **钛铁矿碳热氯化（`gt.recipe.calciner`）**：
   - 对 `carbon` $\in \{\text{`Carbon`}, \text{`CoalCoke`}\}$：
     `1 × dust Ilmenite` + `3 × dust <carbon>` + `GenGas_Chlorine (7000)` $\rightarrow$ `1 × dust FerricChloride` + `GenLiquid_CrudeTitaniumTetrachloride (1000)` + `GenGas_CarbonMonoxide (3000)`；64 EU/t，200 ticks。
3. **副产三氯化铁氧化再生氯气（`gt.recipe.calciner`）**：
   - `2 × dust FerricChloride` + `Oxygen (1500)` $\rightarrow$ `1 × dust Hematite` + `GenGas_Chlorine (3000)`；48 EU/t，120 ticks。
   - 说明：少量留作 M4 聚异丁烯 Lewis 酸催化剂，大宗副产直接氧化成赤铁矿并把氯气退回氯化炉。

### 3.2 粗四氯化钛精馏除钒与金属钒制备

1. **蒸馏塔高效除钒（`gt.recipe.distillationtower`）**：
   - `GenLiquid_CrudeTitaniumTetrachloride (10000)` $\rightarrow$ `GenLiquid_TitaniumTetrachloride (9500)` + `GenLiquid_VanadiumOxytrichloride (500)`；64 EU/t，200 ticks。
2. **蒸馏室早期小批量除钒（`gt.recipe.distillery`）**：
   - `circuit(1)`（不消耗）+ `GenLiquid_CrudeTitaniumTetrachloride (1000)` $\rightarrow$ `GenLiquid_TitaniumTetrachloride (900)` + `GenLiquid_VanadiumOxytrichloride (100)`；48 EU/t，100 ticks。
3. **三氯氧钒水解制五氧化二钒（`gt.recipe.mixer`）**：
   - `GenLiquid_VanadiumOxytrichloride (2000)` + `DistW (3000)` $\rightarrow$ `1 × dust VanadiumPentoxide` + `GenGas_HydrochloricAcid (6000)`；48 EU/t，160 ticks。
4. **钒铁磁铁矿焙烧浸出提钒（`gt.recipe.calciner`，补充钒源）**：
   - `1 × dust VanadiumMagnetite` + `1 × dust SodiumCarbonate` + `Oxygen (1000)` $\rightarrow$ `1 × dust Hematite` + `1 × dust VanadiumPentoxide` + `CarbonDioxide (1000)`；64 EU/t，200 ticks。
5. **五氧化二钒热还原制金属钒（`gt.recipe.calciner`）**：
   - **钙热还原**：`1 × dust VanadiumPentoxide` + `5 × dust Calcium` $\rightarrow$ `2 × dust Vanadium` + `5 × dust Quicklime`；96 EU/t，200 ticks。
   - **铝热还原**：`3 × dust VanadiumPentoxide` + `10 × dust Aluminium` $\rightarrow$ `6 × dust Vanadium` + `5 × dust Alumina`；96 EU/t，240 ticks。

### 3.3 Kroll 法镁热还原制海绵钛与镁-氯闭环

1. **Kroll 密闭还原（`gt.recipe.calciner`）**：
   - `2 × dust Magnesium` + `GenLiquid_TitaniumTetrachloride (1000)` + `GenGas_Argon (100)` $\rightarrow$ `1 × dust TitaniumSponge` + `2 × dust MagnesiumChloride` + `GenGas_Argon (100)`；96 EU/t，240 ticks。
   - 说明：氩气作为保护气氛输入并等量输出（净零消耗）；产出的 `MagnesiumChloride` 由 GT6CE 内置 `gt.recipe.electrolyzer`（`1 × dust MgCl2 -> 1 × dust Mg + 2000 mB Cl2`）再生为镁与氯气；`TitaniumSponge` 进卡 2 的 `ssite:var_furnace` 重熔得液态 `Titanium` 并浇铸成锭。
