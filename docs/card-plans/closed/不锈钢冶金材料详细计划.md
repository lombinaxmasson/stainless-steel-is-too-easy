## 0. 它解决什么

把“一步到位的不锈钢”拆成真实的火法/湿法中间体，并建立 **高碳不锈钢粗钢（一级）$\rightarrow$ 原版 304 不锈钢（二级）$\rightarrow$ 316L 钼不锈钢（三级）** 的材料梯队。同时提供真正耐卤水与强酸点蚀的 316L 流体管道。

## 1. 行为

- 在 `SsiteMaterials.materials()` 中声明 7 种新材料：
  1. `Ferrochromium`（铬铁 / Ferrochromium）：`color(0xB4A8B8)`、`chemicalFormula("FeCr2")`、`meltingPointKelvin(2160)`、`boilingPointKelvin(3000)`、`density(7.2F)`、`metal()`。
  2. `Ferrosilicon`（硅铁 / Ferrosilicon）：`color(0x7A8288)`、`chemicalFormula("FeSi3")`、`meltingPointKelvin(1683)`、`boilingPointKelvin(2800)`、`density(4.8F)`、`metal()`。
  3. `CarburizedStainlessSteel`（高碳不锈钢 / Carburized Stainless Steel）：`color(0x8E929E)`、`chemicalFormula("Fe6Cr2NiMnC2")`、`meltingPointKelvin(1750)`、`boilingPointKelvin(2950)`、`density(7.7F)`、`metal()`。
  4. `StainlessSteel316L`（316L 钼不锈钢 / 316L Stainless Steel）：`color(0xD4DCE8)`、`chemicalFormula("Fe6Cr2NiMo")`、`meltingPointKelvin(1970)`、`boilingPointKelvin(3100)`、`density(8.0F)`、`metal()`。
  5. `SodiumChromate`（铬酸钠 / Sodium Chromate）：`color(0xF0D830)`、`chemicalFormula("Na2CrO4")`、`dust()`。
  6. `SodiumDichromate`（重铬酸钠 / Sodium Dichromate）：`color(0xE86818)`、`chemicalFormula("Na2Cr2O7")`、`dust()`。
  7. `AodSlag`（AOD 精炼炉渣 / AOD Refining Slag）：`color(0x6E685C)`、`chemicalFormula("CaSiO3·Cr2O3")`、`dust()`。
- 在 `SsiteMachines.fluidPipes()` 中声明 `StainlessSteel316L` 流体管：
  - `new FluidPipeDeclaration("stainless_steel_316l", "StainlessSteel316L", 300, true, true, false, false, 0, 0)`（基础流量 300 mB/t，防气 `gasProof = true`，防酸 `acidProof = true`，耐温按熔点 1.25 倍自动计算）。
- 语言文件：
  - `assets/gt6ce/lang/en_us.json` 与 `zh_cn.json`：写入 7 个 `material.gt6ce.<小写材料名>` 键。
  - `assets/ssite/lang/en_us.json` 与 `zh_cn.json`：写入 `block.ssite.pipe_<size>_stainless_steel_316l`（`tiny`、`small`、`medium`、`large`、`huge`、`quadruple`、`nonuple` 共 7 档）的中英文名称。

## 2. 明确不做

- 不给 `CarburizedStainlessSteel` 做单独的禁用零件前缀 hack（它只作为初炼产出和 AOD 原料使用）
- 不在这张卡里加 AOD 转炉机器
