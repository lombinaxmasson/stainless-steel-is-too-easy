## 0. 它解决什么

把整条「铬铁矿 $\rightarrow$ 铬铁 + 硅铁 $\rightarrow$ 高碳不锈钢粗钢 $\rightarrow$ AOD 转炉三档吹炼 304 / 纯氩吹炼 316L」的配方链写入游戏，让玩家先用空气硬吹攒出第一座深冷塔，再用氮氧和氩氧逐步提升收率并解锁 316L。

## 1. 行为

- **铬线分流与硅铁制备**（在 `ChemistryRecipes.add(Context)` 中写入内置配方表，每条均检查 `map.add(...) != null`）：
  1. **冶金级铬铁 (`Ferrochromium`)**：`gt.recipe.calciner`（或 `gt.recipe.burnmixer`）：`Chromite` 粉 + `Quicklime` 粉 + `Coke` / `Carbon` 粉 $\rightarrow$ `Ferrochromium` 粉 + `CO` 气体。
  2. **化工级纯铬 (`Chromium`)**：
     - 氧化焙烧（`gt.recipe.roaster` / `gt.recipe.calciner`）：`Chromite` 粉 + `SodiumCarbonate` 粉 + `Oxygen` $\rightarrow$ `SodiumChromate` 粉 + 氧化铁副产。
     - 酸化转重铬酸钠（`gt.recipe.bath` / `gt.recipe.mixer`）：`SodiumChromate` 粉 + 硫酸 (`H2SO4`) $\rightarrow$ `SodiumDichromate` 粉。
     - 碳还原 + 铝热还原（`gt.recipe.burnmixer`）：`SodiumDichromate` 粉 + `Carbon` 粉 $\rightarrow$ 氧化铬中间态；再与 `Aluminium` 粉铝热反应得高纯 `Chromium` 粉 + `Alumina` 粉。
  3. **硅铁脱氧剂 (`Ferrosilicon`)**：`gt.recipe.calciner` / `gt.recipe.burnmixer`：`Quartzite` / `SiliconDioxide` 粉 + `Iron` 粉 + `Carbon` 粉 $\rightarrow$ `Ferrosilicon` 粉 + `CO` 气体。
- **第一步：坩埚初炼高碳不锈钢粗钢 (`CarburizedStainlessSteel`)**（在 `SsiteMaterials.crucibleReactions()` 中声明）：
  - 6 份铁源（`Iron` / `WroughtIron` / `PigIron` / `MeteoricIron`）+ 1 份 `Nickel` + 1 份 `Ferrochromium` + 1 份 `Manganese` $\rightarrow$ 9 份 `CarburizedStainlessSteel`。
  - 4 份铁源 + 3 份 `Invar` + 1 份 `Ferrochromium` + 1 份 `Manganese` $\rightarrow$ 9 份 `CarburizedStainlessSteel`。
- **第二步：AOD 转炉三档吹炼标准不锈钢 (`StainlessSteel` / 304)**（写入 `ssite.recipe.aod`）：
  1. **早期破局档（空气硬吹，50% 收率）**：
     - 输入：`9 × dust CarburizedStainlessSteel` + `1 × dust Ferrosilicon` + `2 × dust Quicklime` + `Air (4000 mB)`
     - 输出：`5 × dust StainlessSteel`（或对应锭）+ `4 × dust AodSlag` + `CO (1000 mB)`
     - 耗能与时长：32 HU/t（或 EU/t），400 ticks（慢、烧损近半，但无需深冷塔！）
  2. **中期氮氧档（$\text{O}_2 + \text{N}_2$，约 78% 收率）**：
     - 输入：`9 × dust CarburizedStainlessSteel` + `1 × dust Ferrosilicon` + `1 × dust Quicklime` + `1 × dust Fluorite` + `Oxygen (2000 mB)` + `Nitrogen (2000 mB)`
     - 输出：`7 × dust StainlessSteel` + `2 × dust AodSlag` + `CO (1000 mB)`
     - 耗能与时长：64 HU/t，240 ticks
  3. **成熟氩氧档（$\text{O}_2 + \text{Ar}$，100% 满收率）**：
     - 输入：`9 × dust CarburizedStainlessSteel` + `1 × dust Ferrosilicon` + `1 × dust Quicklime` + `1 × dust Fluorite` + `Oxygen (1500 mB)` + `Argon (500 mB)`
     - 输出：`9 × dust StainlessSteel` + `1 × dust AodSlag` + `CO (1000 mB)`
     - 耗能与时长：64 HU/t，120 ticks
- **第三步：纯氩 AOD 冶炼 316L 钼不锈钢 (`StainlessSteel316L`)**（写入 `ssite.recipe.aod`）：
  - 输入：`8 × dust CarburizedStainlessSteel` + `1 × dust Molybdenum` + `1 × dust Ferrosilicon` + `1 × dust Fluorite` + `Oxygen (1500 mB)` + `Argon (1000 mB)`
  - 输出：`9 × dust StainlessSteel316L` + `1 × dust AodSlag` + `CO (1000 mB)`
  - 耗能与时长：64 HU/t，160 ticks
- **炉渣回收**（`gt.recipe.centrifuge`）：
  - `4 × dust AodSlag` $\rightarrow$ `1 × dust Chromite` + `2 × dust Quicklime` + `1 × dust SiliconDioxide`（把早期空气硬吹烧损的铬救回来一部分！）。

## 3. 验收

- [x] `ChemistryRecipes.add` 启动无异常，所有 `map.add` 均返回非空 `Line`
- [x] 坩埚能炼出 `CarburizedStainlessSteel`，不能直接炼出 `StainlessSteel`
- [x] `ssite.recipe.aod` 中能查到空气、氮氧、氩氧三条 304 路线与一条 316L 路线
- [x] 炉渣能在离心机回收铬铁矿粉
- [x] `.\scripts\build.ps1` 双加载器编译通过

NeoForge 1.21.1 专用服（2026-10-22）能进到 `Done`。`ChemistryRecipes.add` 在拒绝或缺少粉/流体时会抛 `ssite recipe rejected` / `ssite missing dust` / `ssite missing fluid`，这次没有。

- 坩埚合金展示从 135 条变成 143 条，正好是 8 条高碳粗钢（4 种铁源 × 镍/殷钢）。`StainlessSteel` 仍只有原来那 2 条被删：产量 9 和产量 36。
- 机器配方基线从 227392 行变成 227412 行。多出来的 20 行是 12 条机器配方（铬铁 2、铬盐 2、纯铬 1、硅铁 2、AOD 4、炉渣离心 1）加上这 8 条坩埚反应。覆盖层 `removed 12, added 0, rejected 0`，搅拌机不锈钢删除没有被新配方冲掉。
- 焙烧炉只有一个物品输入，纯碱焙烧改走煅烧炉。没有单独的三氧化二铬材料，燃烧搅拌机又只有一个物品输出，所以碳还原和铝热并成一条煅烧炉：重铬酸钠 + 碳 + 铝 → 铬 + 氧化铝 + 纯碱 + 一氧化碳。氧化铁副产用 `Hematite`。焦炭材料名是 `CoalCoke`。316L 只接了高碳粗钢进料。
- 流体字段是 `Air`、`Oxygen`、`Nitrogen`、`Argon`、`GenGas_CarbonMonoxide`、`GenLiquid_SulfuricAcid`。`Quartzite` 粉能解析到。Forge 和 NeoForge 的 `FluidStack` 包名不同，流体包装在两边各一份 `FluidBridge` 里，公共配方源不写这个类型名。
