## 0. 它解决什么

M7 第 1 卡删掉了 `Galena` 的一步焙烧（`Roaster: Galena → Ag + Pb`）、坩埚直熔与锑矿/黝铜矿的一步焙烧，但铅、锑、铋都没有替代产线：

- **铅**：本移植里 `Galena` 焙烧被删后没有任何铅来源；
- **锑**：`Stibnite` 与 `Tetrahedrite` 的焙烧行都被第 1 卡删除，锑没有来源；
- **铋**：GT6CE 里没有任何铋配方，而 M3 的聚合物卡已经需要 `Bismuth`；
- **砷**：只剩 `Realgar` 一步焙烧，`Arsenopyrite` / `Cobaltite` 的焙烧行已删；
- **银**：第 2 卡从铜阳极泥回收银，方铅矿这一路的高银铅还没有利用。

本卡按经典火法炼铅把方铅矿拆成五步：**焙烧 → 还原 → 除铜 → 哈里斯软化 → 帕克斯脱银 → 克罗尔-贝特顿脱铋**，每一步顺手把杂质变成可回收的渣。

## 3. 配方设计

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 方铅矿氧化焙烧 | `calciner` | 2 Galena + 3000 O₂ → 2 LeadCalcine + 2000 SO₂ | 240 / 64 |
| 铅焙砂碳还原 | `calciner` | 2 LeadCalcine + 2 CoalCoke → 2 CrudeLead + 2000 CO | 240 / 80 |
| 除铜浮渣 | `calciner` | 2 CrudeLead + 1 Sulfur → 2 DrossedLead + 1 CopperDross | 200 / 64 |
| 哈里斯碱熔软化 | `calciner` | 2 DrossedLead + 4 SodiumHydroxide + 2 SodiumNitrate → 2 SoftenedLead + 1 SodiumArsenate + 1 SodiumAntimonate | 240 / 96 |
| 砷酸钠碳还原 | `calciner` | 2 SodiumArsenate + 3 CoalCoke → 2 Arsenic + 3 SodiumCarbonate | 200 / 64 |
| 锑酸钠碳还原 | `calciner` | 2 SodiumAntimonate + 3 CoalCoke → 2 Antimony + 3 SodiumCarbonate | 200 / 64 |
| 帕克斯加锌脱银 | `calciner` | 2 SoftenedLead + 2 Zinc → 2 DesilveredLead + 1 SilverZincCrust | 240 / 80 |
| 银锌壳离心分离 | `centrifuge` | 2 SilverZincCrust → 1 Silver + 2 Zinc | 200 / 64 |
| 克罗尔-贝特顿脱铋 | `calciner` | 2 DesilveredLead + 1 Calcium + 1 Magnesium → 2 Lead + 1 BismuthDross | 240 / 96 |
| 铋渣氯化回收 | `calciner` | 2 BismuthDross + 1000 Cl₂ → 2 Bismuth + 1 CalciumChloride + 1 MagnesiumChloride | 200 / 64 |

说明：

- **焙烧与还原**：PbS + 3/2 O₂ → PbO + SO₂，再用焦炭把 PbO 还原成粗铅（PbO + C → Pb + CO）。硫进 SO₂ 接回硫酸线，碳进 CO。
- **除铜**：向熔铅里加硫，铜以 Cu₂S 浮渣析出；铜浮渣作为副产物保留，留给以后的铜线消纳。
- **哈里斯软化**：熔铅用烧碱与硝酸钠氧化，砷、锑分别变成砷酸钠与锑酸钠浮渣；两种钠盐再用焦炭还原成砷、锑。`calciner` 有 3 个物品输入/输出槽，正好容纳「铅 + 碱 + 硝酸钠」进、「软化铅 + 两种钠盐」出。
- **帕克斯脱银**：向软化铅里加锌，银与锌形成高熔点银锌壳浮起；银锌壳用离心机拆成银与锌，锌回到本步骤循环。
- **克罗尔-贝特顿**：脱银铅加钙、镁生成铋渣；铋渣氯化后钙镁进氯化物、铋还原成金属。
- 4 份方铅矿 → 4 份粗铅 → 4 份软化铅 → 4 份脱银铅 → 4 份精铅，同时副产 1 份银、少量砷/锑/铋；铅是主线，其余是伴生。

## 4. 与总览/上游设计的偏差（开工前确认）

1. **砷、锑分两行还原**：`calciner` 一次能出 3 个物品，但把两种钠盐放进同一行会让配方过于拥挤、也不利于 EMI 阅读；本卡让哈里斯行同时产出两种钠盐，再各用一条碳还原行拆出金属。
2. **银锌壳用离心机**：本移植没有真空蒸馏炉，银锌壳按物相用 `centrifuge` 分离成银与锌，回收的锌回到帕克斯步骤，符合工业上锌循环的思路。
3. **铋渣直接氯化**：总览写「钙镁脱铋」，本卡把铋渣的氯化与还原合并成一行（Cl₂ 把钙镁转成氯化物，铋留下），不新增氯化焙烧中间体。
4. **不新增移除规则**：方铅矿与辉锑矿/黝铜矿的焙烧、坩埚直熔已在 M7 第 1 卡删除，本移植也没有方铅矿的纯酸浸 Bath 行；本卡只补正线。
5. **保留 `Realgar` 焙烧**：雄黄一步焙烧出砷是第 1 卡有意保留的矿石入口，本卡不抢它的位置。
