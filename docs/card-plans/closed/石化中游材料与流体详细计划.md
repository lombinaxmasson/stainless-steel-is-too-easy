## 0. 它解决什么

GT6CE 的石化只有一层皮：内置流体里有原油（`Oil_Light`、`Oil_Normal`、`Oil_Medium`、`Oil_Heavy`、`Oil_ExtraHeavy`）、轻烃（`Methane`、`Propane`、`Butane`、`LPG`）、两种烯烃（`Ethylene`、`Propylene`）和成品燃料（`Petrol`、`Kerosine`、`Diesel`、`Fuel`、`Lubricant`、`Tar`），但**苯、甲苯、二甲苯、丁烯、丁二烯、异戊二烯、苯酚、丙酮一个都没有**，原油也没有任何蒸馏配方。

本卡一次性把 M3 要用的材料全部注册好，让后面的产线卡只写配方：

1. **炼油与裂解中间物流**：石脑油、重整油、裂解汽油、裂解 C4、抽余油；
2. **萃取溶剂与萃取液**：糠醛、环丁砜，以及各自的富溶剂萃取液（溶剂必须能在汽提塔里回收，所以萃取液要分开两种）；
3. **芳烃单体**：BTEX 混合芳烃、苯、甲苯、乙苯、混合二甲苯、邻/间/对二甲苯、间对二甲苯混液、联苯；
4. **C4 / C5 单体**：混合丁烯、1-丁烯、2-丁烯、异丁烯、丁二烯、乙醛（乙醇法丁二烯），C5 馏分、二聚 C5、异戊二烯、环戊二烯、双环戊二烯、戊烷、降冰片烯；
5. **苯酚丙酮链**：异丙苯、过氧化氢异丙苯、苯酚、丙酮、双酚 A；
6. **催化剂**：ZSM-5 分子筛。

所有流体材料走 `.liquid()` 或 `.gas()`，自动注册 `GenLiquid_<Name>` / `GenGas_<Name>`；常温为固体的单体走 `.dust()`；对二甲苯同时声明 `.dust()` 与 `.liquid()`（结晶出粉，熔化回液）。

## 2. 明确不做

- 不重复注册 GT6CE 已内置的 `Methane`、`Propane`、`Butane`、`LPG`、`Ethylene`、`Propylene`、`Hydrogen`、`Steam`、`Oxygen`、`Air`、`Petrol`、`Kerosine`、`Diesel`、`Fuel`、`Lubricant`、`Tar`、`Oil_*`、`BioEthanol`、`Zeolite`、`Platinum`、`Tantalum` 等材料或流体
- 不注册路线图 3.1「基础衍生物单体」里的氯乙烯、醋酸乙烯、环氧乙烷、乙二醇、环氧氯丙烷、丙烯腈、丙烯酸、MMA、苯酐、PTA、间苯二甲酸、己内酰胺、MDI（这些需要二氯乙烷、乙酸、氢氰酸、甲醇、甲醛、苯胺、光气等整套上游，移交 M4 各高分子家族卡按需注册）
- 不注册甲醛、二甲基二噁烷与固体磷酸（Prins 法合成异戊二烯移交 M4，与酚醛树脂的甲醛线一起做）
- 不注册多氯联苯（联苯氯化变压器油留到 M6 冷却剂挂载）
- 不给任何有机物声明 `metal()` 或 `polymer()`
- 不写配方（第 2～7 张卡）
