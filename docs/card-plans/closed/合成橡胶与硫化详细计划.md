# 合成橡胶、硅橡胶与硫化详细计划

> 计划 slug：`m4/rubber-vulcanization`
> 状态：关闭。本文件位于 `docs/card-plans/closed/`。前置是 [`C3/C4 平台化学品`](C3平台化学品与Prins异戊二烯详细计划.md)（需要丙烯腈、甲醇）和 [`苯乙烯与离子交换树脂`](苯乙烯离子交换树脂与PMMA详细计划.md)（需要苯乙烯）。
> 性质：M4 第二批收官。M3 的丁二烯、异戊二烯在这里落地成四种通用合成胶，再加上硅橡胶；同时建立统一的硫化模型和三种硫化助剂（炭黑、氧化锌、氧化镁）。

## 0. 它解决什么

- M3 的**丁二烯**和**异戊二烯**一直没有下游。
- GT6CE 的 `Rubber` 只能从乳胶凝固拿到。本卡让**合成聚异戊二烯硫化直接产出 GT6 `Rubber`**，从此橡胶可以完全走石化路线。
- 统一硫化模型：**生胶 + 少量炭黑 + 微量硫 + 氧化锌（不消耗）→ 硫化胶锭**。

  | 胶种 | 硫化体系 | 产物 |
  |---|---|---|
  | 聚异戊二烯 | 标准 | GT6 `Rubber` |
  | 丁苯（SBR） | 标准 | 新材料 |
  | 丁腈（NBR，耐油） | 标准 | 新材料 |
  | 氯丁（CR，耐候） | 氧化镁 + 氧化锌，不用硫 | 新材料 |
  | 硅橡胶 | 过氧化物 + 白炭黑 | 新材料 |
  | 硬质胶 | 大量硫 | 新材料 |

- 硫化胶都声明为 `metal()`，和 GT6 `Rubber` 同构，自动获得锭、板、环等形态，后续可以直接做密封圈。

## 2. 配方（`PolymerRecipes.rubberVulcanization()`）

- **助剂**
  1. 炉法炭黑（`gt.recipe.calciner`）：`Fuel (1000)` + `Oxygen (500)` $\rightarrow$ `2 × dust CarbonBlack` + `CarbonDioxide (500)`；48 EU/t，160 ticks
  2. 热裂法炭黑（`gt.recipe.calciner`）：`Methane (1000)` $\rightarrow$ `1 × dust CarbonBlack` + `Hydrogen (2000)`；48 EU/t，160 ticks
  3. 氧化锌（`gt.recipe.roaster`）：`1 × dust Zinc` + `Oxygen (1000)` $\rightarrow$ `1 × dust ZincOxide`；32 EU/t，120 ticks
  4. 氧化镁（`gt.recipe.calciner`）：`1 × dust MagnesiumHydroxide` $\rightarrow$ `1 × dust MagnesiumOxide` + `Steam (1000)`；32 EU/t，120 ticks
- **生胶**
  1. 聚异戊二烯（`gt.recipe.mixer`）：`1 × dust Aluminium`（不消耗）+ `TitaniumTetrachloride (10)` + `GenLiquid_Isoprene (1000)` $\rightarrow$ `1 × dust RawPolyisoprene`；64 EU/t，200 ticks
  2. 乳液丁苯（`gt.recipe.mixer`）：`GenGas_Butadiene (750)` + `GenLiquid_Styrene (250)` + `GenLiquid_DeionizedWater (1000)` + `GenLiquid_CumeneHydroperoxide (10)` $\rightarrow$ `1 × dust RawStyreneButadieneRubber` + `DistW (1000)`；48 EU/t，200 ticks
  3. 乳液丁腈（`gt.recipe.mixer`）：`GenGas_Butadiene (700)` + `GenLiquid_Acrylonitrile (300)` + `GenLiquid_DeionizedWater (1000)` + `GenLiquid_CumeneHydroperoxide (10)` $\rightarrow$ `1 × dust RawNitrileRubber` + `DistW (1000)`；48 EU/t，200 ticks
  4. 丁二烯氯化（`gt.recipe.mixer`）：`GenGas_Butadiene (1000)` + `GenGas_Chlorine (1000)` $\rightarrow$ `GenLiquid_Dichlorobutene (1000)`；32 EU/t，120 ticks
  5. 脱氯化氢（`gt.recipe.bath`）：`1 × dust SodiumHydroxide` + `GenLiquid_Dichlorobutene (1000)` $\rightarrow$ `1 × dust Salt` + `GenLiquid_Chloroprene (1000)` + `DistW (1000)`；32 EU/t，120 ticks
  6. 乳液氯丁（`gt.recipe.mixer`）：`GenLiquid_Chloroprene (1000)` + `GenLiquid_DeionizedWater (1000)` + `GenLiquid_CumeneHydroperoxide (10)` $\rightarrow$ `1 × dust RawNeoprene` + `DistW (1000)`；48 EU/t，200 ticks
- **有机硅**
  1. 一氯甲烷（`gt.recipe.mixer`）：`circuit(1)` + `GenLiquid_Methanol (1000)` + `GenGas_HydrochloricAcid (1000)` $\rightarrow$ `GenGas_Chloromethane (1000)` + `DistW (1000)`；32 EU/t，120 ticks
     - 不加电路的话，本行输入是卡 4 氯甲基化（交联 PS + 甲醛 + 氯化氢 + 甲醇）的子集。
  2. Rochow 直接法（`gt.recipe.mixer`）：`1 × dust Copper`（不消耗）+ `1 × dust Silicon` + `GenGas_Chloromethane (2000)` $\rightarrow$ `GenLiquid_Dimethyldichlorosilane (1000)`；64 EU/t，200 ticks
  3. 水解缩聚（`gt.recipe.mixer`）：`GenLiquid_Dimethyldichlorosilane (1000)` + `DistW (1000)` $\rightarrow$ `GenLiquid_Polydimethylsiloxane (1000)` + `GenGas_HydrochloricAcid (2000)`；32 EU/t，160 ticks
- **硫化**（全部在 `gt.recipe.mixer`，48 EU/t，200 ticks；`ZincOxide` / `MagnesiumOxide` 均不消耗）
  1. 聚异戊二烯：`1 × dust RawPolyisoprene` + `1 × dustSmall CarbonBlack` + `1 × dustTiny Sulfur` + `1 × dust ZincOxide` $\rightarrow$ `1 × ingot Rubber`（GT6 自带）
  2. 丁苯：`1 × dust RawStyreneButadieneRubber` + 同样的炭黑 / 硫 / 氧化锌 $\rightarrow$ `1 × ingot StyreneButadieneRubber`
  3. 丁腈：`1 × dust RawNitrileRubber` + 同样的炭黑 / 硫 / 氧化锌 $\rightarrow$ `1 × ingot NitrileRubber`
  4. 氯丁：`1 × dust RawNeoprene` + `1 × dustSmall CarbonBlack` + `1 × dust MagnesiumOxide` + `1 × dust ZincOxide` $\rightarrow$ `1 × ingot Neoprene`
  5. 硅橡胶：`1 × dust SiliconDioxide` + `GenLiquid_Polydimethylsiloxane (1000)` + `GenLiquid_CumeneHydroperoxide (10)` $\rightarrow$ `1 × ingot SiliconeRubber`
  6. 硬质胶：`circuit(1)` + `1 × dust RawPolyisoprene` + `1 × dust Sulfur` + `1 × dust ZincOxide` $\rightarrow$ `1 × dust Ebonite`
     - 物品种类上，本行是聚异戊二烯硫化那一行的子集，所以必须加电路。
  7. 硬质胶走 `polymerForming`（压板 + 轧箔）。

## 3. 明确不做

- 不做硫化模具和定型硫化（直接出锭，后续形态交给 GT6 的通用金属加工）
- 不做丁基胶、乙丙胶（EPDM）、溶聚丁苯、顺丁胶
- 不做促进剂、防老剂、增塑剂
- 不做有机硅单体的歧化 / 精馏（一甲基三氯硅烷等副产不出槽），也不做硅树脂、室温硫化硅胶
- 氟橡胶（Viton）归第 11 张氟化工卡
