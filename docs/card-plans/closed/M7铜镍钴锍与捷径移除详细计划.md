## 0. 它解决什么

GT6CE 的硫化矿有三类捷径：

| 捷径 | 本移植里的实际状态 | 处理 |
|---|---|---|
| 电解机常温拆出金属 | **只有砷铂矿 (`Sperrylite`) 带 `ELECTROLYSER` 权限**，其余七种硫化矿没有电解行 | 移除砷铂矿电解行；其余不写空规则 |
| 焙烧炉一步出金属 | 闪锌矿、辉钼矿、辉锑矿、镍黄铁矿、黄铜矿、砷黄铁矿、辉钴矿、方铅矿、硫铂矿、黝铜矿共 10 行 | 全部移除 |
| 普通坩埚直熔 | 辉钼矿、闪锌矿、辉锑矿、镍黄铁矿、黄铜矿、方铅矿、硫铂矿、砷铂矿共 8 个熔炼目标 | 用 `smeltingTargetRemovals()` 清空 |
| 铂族泥离心直拆 | `PlatinumGroupSludge` 的 dust / small / tiny / crushed / crushed-tiny 五种形态 | 全部移除，改由第 2 卡氯络合分离 |

**与总览描述的偏差（开工前确认）**：总览写「所有硫化矿都能电解直拆」，本移植实际只有砷铂矿有电解行；另外 `Cobaltite` / `Arsenopyrite` / `Tetrahedrite` 有焙烧行但没有坩埚熔炼目标，`Sperrylite` 有坩埚目标但没有焙烧行。移除规则按实际存在的行走，不写匹配不到任何东西的空规则。

移除后的过渡期：铅、锌、银、锑、砷、铂族与钼暂时没有获取路线，分别由第 2–5 张卡补回。本包尚未发布，不做旧存档兼容。

## 2. 移除的原版捷径

### 2.1 焙烧一步出金属（`gt.recipe.roaster`，10 条）

| 文件 | 匹配输入 |
|---|---|
| `remove_roaster_chalcopyrite.json` | `gt6ce:dust_chalcopyrite` |
| `remove_roaster_pentlandite.json` | `gt6ce:dust_pentlandite` |
| `remove_roaster_sphalerite.json` | `gt6ce:dust_sphalerite` |
| `remove_roaster_galena.json` | `gt6ce:dust_galena` |
| `remove_roaster_molybdenite.json` | `gt6ce:dust_molybdenite` |
| `remove_roaster_cooperite.json` | `gt6ce:dust_cooperite` |
| `remove_roaster_cobaltite.json` | `gt6ce:dust_cobaltite` |
| `remove_roaster_arsenopyrite.json` | `gt6ce:dust_arsenopyrite` |
| `remove_roaster_stibnite.json` | `gt6ce:dust_stibnite` |
| `remove_roaster_tetrahedrite.json` | `gt6ce:dust_tetrahedrite` |

不写匹配数量的写法（省略 `count` = 任意数量），与 M6 的移除规则一致。`Pyrite`（只出 SO₂ + Fe₂O₃）、`Realgar`（出砷）、`Stannite` / `Kesterite`（锡铜路线留待后续）不动。

### 2.2 砷铂矿电解（`gt.recipe.electrolyzer`，1 条）

`remove_electrolyzer_sperrylite.json` 匹配 `gt6ce:dust_sperrylite`。本移植没有其余硫化矿的电解行，不写空规则。

### 2.3 铂族泥离心（`gt.recipe.centrifuge`，5 条）

按 `GTOresGen` 的五种形态各一条：`dust_platinumgroupsludge`、`dust_small_platinumgroupsludge`、`dust_tiny_platinumgroupsludge`、`crushed_centrifuged_platinumgroupsludge`、`crushed_centrifuged_tiny_platinumgroupsludge`。

### 2.4 坩埚直熔（Java，8 条）

在 `SsiteMaterials.smeltingTargetRemovals()` 现有三个 M6 条目后追加：
`Chalcopyrite`、`Pentlandite`、`Sphalerite`、`Galena`、`Molybdenite`、`Cooperite`、`Sperrylite`、`Stibnite`。

## 4. 配方设计

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 黄铜矿造锍 | `calciner` | 3 Chalcopyrite + 1500 O₂ → 3 GreenMatte + 1 Hematite + 1500 SO₂ | 240 / 64 |
| 镍黄铁矿造锍 | `calciner` | 3 Pentlandite + 1200 O₂ → 3 GreenMatte + 1 Hematite + 1200 SO₂ | 240 / 64 |
| 吹炼白锍 | `calciner` | 3 GreenMatte + 1000 O₂ → 2 WhiteMatte + 1 Hematite + 1000 SO₂ | 240 / 80 |
| 白锍氧化酸浸 | `mixer` | 2 WhiteMatte + 1000 H₂SO₄ + 500 O₂ + 1000 蒸馏水 → 2 CrudeCopper + 1000 镍钴硫酸盐溶液 | 200 / 64 |
| P204 提钴 | `mixer` | 1000 镍钴硫酸盐溶液 + 500 P204 → 1000 硫酸镍溶液 + 1000 钴负载 P204 | 160 / 64 |
| 钴反萃 | `mixer` | 1000 钴负载 P204 + 500 H₂SO₄ → 1000 硫酸钴溶液 + 480 P204 | 160 / 48 |
| 镍电积 | `electrolyzer` | 1000 硫酸镍溶液 → 1 Nickel + 950 H₂SO₄ + 500 O₂ | 240 / 96 |
| 钴电积 | `electrolyzer` | 1000 硫酸钴溶液 → 1 Cobalt + 950 H₂SO₄ + 500 O₂ | 240 / 96 |
| 粗铜电解精炼 | `electrolyzer` | 2 CrudeCopper + 1000 H₂SO₄ → 2 Copper + 1 铜阳极泥 + 25% 1 铂族精矿 + 950 H₂SO₄ | 300 / 128 |

设计说明：

- 造锍与吹炼沿用 `calciner`（M1–M6 的焙烧/还原主力机），不新增机器；黄铜矿与镍黄铁矿走同一条绿锍线，白锍统一代表铜镍硫化物精料。
- 铁在造锍/吹炼中以 `Hematite` 副产出去，不引入新的炉渣材质。
- P204 在低酸下优先负载钴，镍留在萃余液；反萃回收 96% 有机相，符合 M6 的 95% 写法。
- 电解精炼用 `SulfuricAcid` 作电解液并回收 95%；阳极泥必出，铂族精矿 25% 概率（1/10000 单位下的 `2500`），平均 8 批粗铜出 1 份，供第 2 卡氯络合分离使用。
