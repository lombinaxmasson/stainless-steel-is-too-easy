## 0. 它解决什么

M7 第 1 卡把粗铜电解精炼拆成 **高纯铜 + 铜阳极泥 + 铂族精矿**，但这两股渣目前没有任何出口。本卡给它们补上完整的伴生回收线：

| 原料 | 一路去哪 | 另一路去哪 |
|---|---|---|
| `CopperAnodeSlime`（铜阳极泥） | 氧化焙烧蒸出 `SeO2` / `TeO2`，`SO2` 还原得 **硒 `Selenium` / 碲 `Tellurium`** | 硝酸分银留金，铜置换得 **银 `Silver`**，粗金经氯金酸与 `SO2` 还原得 **金 `Gold`** |
| `PlatinumGroupConcentrate`（铂族精矿） | 王水溶解成氯络合物母液 | 依次蒸出 **锇 `Osmium` / 钌 `Ruthenium`**，氯化铵沉 **铂 `Platinum`**，氨络合沉 **钯 `Palladium`**，六氯铱酸铵沉 **铱 `Iridium`**，最后氢还原 **铑 `Rhodium`** |
| `Cooperite` / `Sperrylite` | 同样进王水溶解，作为铂族的矿石入口 | 硫 / 砷留在溶解渣 |

铂族六兄弟共用一条氯络合物母液、六个平行的还原小循环；锇钌先走，铂钯铱铑依次沉淀。这正是设计文档里 `PlatinumGroupChain.groovy` 的结构。

## 3. 配方设计

### 3.1 铜阳极泥：硒、碲、银、金

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 阳极泥氧化焙烧 | `calciner` | 2 CopperAnodeSlime + 2500 O₂ → 1 SilverGoldResidue + 1 TelluriumDioxide + 2000 SeO₂ + 1000 SO₂ | 240 / 64 |
| 硒还原 | `mixer` | 1000 SeO₂ + 2000 SO₂ + 2000 DistW → 1 Selenium + 2000 H₂SO₄ | 200 / 48 |
| 碲还原 | `mixer` | 1 TelluriumDioxide + 2000 SO₂ + 2000 DistW → 1 Tellurium + 2000 H₂SO₄ | 200 / 48 |
| 硝酸分银 | `mixer` | 2 SilverGoldResidue + 3000 HNO₃ → 1 CrudeGold + 2000 SilverNitrateSolution + 1000 NO | 200 / 64 |
| 铜置换银 | `mixer` | 2000 SilverNitrateSolution + 1 Copper → 2 Silver + 1000 Dirty_Water | 160 / 48 |
| 粗金溶解 | `mixer` | 2 CrudeGold + 2000 HNO₃ + 6000 HCl → 2 ChloroauricAcid + 1000 NO + 2000 DistW | 240 / 64 |
| 金还原 | `mixer` | 2 ChloroauricAcid + 3000 SO₂ + 6000 DistW → 2 Gold + 3000 H₂SO₄ + 8000 HCl | 240 / 64 |

说明：

- 焙烧把铜阳极泥里的硒、碲分别变成挥发性的 SeO₂ 气体与 TeO₂ 粉尘，金银留在 `SilverGoldResidue` 中；这两股氧化物按 2 份阳极泥 → 2 硒 + 1 碲的比例回收。
- 硒碲都用硫化矿造锍副产的 `SO₂` 还原（SeO₂ + 2 SO₂ + 2 H₂O → Se + 2 H₂SO₄；TeO₂ 同理），酸回收进硫酸线，和 M7 第 1 卡的硫回收闭环。
- 银用硝酸浸出后以铜置换（Cu + 2 AgNO₃ → 2 Ag + Cu(NO₃)₂）；硝酸铜进 `Dirty_Water`，不新增铜盐材质。
- 金不溶于硝酸，留下来成为 `CrudeGold`；王水溶解用 GT6CE 已有的 **`ChloroauricAcid` 粉**承载，再用 SO₂ 还原成 `Gold`。

### 3.2 铂族六兄弟：王水母液与依次沉淀

| 步骤 | 机器 | 输入 → 输出 | ticks / EU·t⁻¹ |
|---|---|---|---|
| 铂族精矿溶解 | `mixer` | 1 PlatinumGroupConcentrate + 2000 HNO₃ + 6000 HCl → 1000 PGMChlorideLiquor + 1000 NO | 240 / 64 |
| 硫铂矿溶解 | `mixer` | 1 Cooperite + 2000 HNO₃ + 6000 HCl → 1 Sulfur + 1000 PGMChlorideLiquor + 1000 NO | 240 / 64 |
| 砷铂矿溶解 | `mixer` | 1 Sperrylite + 2000 HNO₃ + 6000 HCl → 1 Arsenic + 1000 PGMChlorideLiquor + 1000 NO | 240 / 64 |
| 蒸锇 | `distillery` | 电路 1 + 1000 PGMChlorideLiquor → 250 OsmiumTetroxide + 750 OsmiumFreePGMLiquor | 240 / 64 |
| 蒸钌 | `distillery` | 电路 2 + 750 OsmiumFreePGMLiquor → 250 RutheniumTetroxide + 500 PGMPreciousLiquor | 240 / 64 |
| 锇还原 | `calciner` | 250 OsmiumTetroxide + 1000 H₂ → 1 Osmium + 1000 DistW | 200 / 64 |
| 钌还原 | `calciner` | 250 RutheniumTetroxide + 1000 H₂ → 1 Ruthenium + 1000 DistW | 200 / 64 |
| 氯化铵配制 | `mixer` | 1000 NH₃ + 1000 HCl → 1000 AmmoniumChlorideSolution | 100 / 32 |
| 沉铂 | `mixer` | 500 PGMPreciousLiquor + 500 AmmoniumChlorideSolution → 1 AmmoniumChloroplatinate + 500 PalladiumLiquor + 500 HCl | 160 / 48 |
| 铂还原 | `calciner` | 1 AmmoniumChloroplatinate + 1000 H₂ → 1 Platinum + 500 AmmoniumChlorideSolution + 2000 HCl | 200 / 64 |
| 沉钯 | `mixer` | 500 PalladiumLiquor + 500 NH₃ → 1 DiamminePalladiumChloride + 500 RhodiumIridiumLiquor + 500 Dirty_Water | 160 / 48 |
| 钯还原 | `calciner` | 1 DiamminePalladiumChloride + 1000 H₂ → 1 Palladium + 1000 NH₃ + 1000 HCl | 200 / 64 |
| 沉铱 | `mixer` | 500 RhodiumIridiumLiquor + 500 AmmoniumChlorideSolution + 250 Cl₂ → 1 AmmoniumHexachloroiridate + 500 RhodiumChlorideSolution + 500 HCl | 160 / 48 |
| 铱还原 | `calciner` | 1 AmmoniumHexachloroiridate + 1000 H₂ → 1 Iridium + 500 AmmoniumChlorideSolution + 2000 HCl | 200 / 64 |
| 铑还原 | `calciner` | 500 RhodiumChlorideSolution + 750 H₂ → 1 Rhodium + 1500 HCl | 200 / 64 |

说明：

- 一条母液拆成五段：`PGMChlorideLiquor` → `OsmiumFreePGMLiquor` → `PGMPreciousLiquor` → `PalladiumLiquor` → `RhodiumIridiumLiquor` → `RhodiumChlorideSolution`；每蒸出一种金属，液体就短一截。
- 锇钌用两台 `distillery` 按电路号顺序蒸馏，四氧化物再各自氢还原成海绵金属；蒸馏器只有 1 个流体输入槽，因此用 `circuit(n)` + `keep(0)` 区分顺序，和第 1 卡钒精馏的写法一致。
- 氯化铵只作氯的载体：沉铂与沉铱共消耗 1000 mB，铂、铱还原各回收 500 mB，整条线净零。
- 铂、钯、铱都以铵盐或氨络合物沉淀，铑留在最后的氯化铑溶液里直接氢还原。全部还原都走 `calciner`（H₂ 气氛），不新增机器。
- 铂族精矿 1 份走完整条线正好产出 6 种金属各 1 份；`Cooperite` / `Sperrylite` 是并行的矿石入口，硫和砷留在溶解渣里，留给第 4 卡砷锑铋线。

## 4. 与总览/上游设计的偏差（开工前确认）

1. **王水不能直接作为流体**：本移植的 `AquaRegia` 只有 gem/dust 形态，`FluidCatalog` 不生成 `GenLiquid_AquaRegia`，GT6CE 自己的王水配方行也因此拿不到流体。本卡把王水拆成 **HNO₃ + 3 HCl** 直接进溶解配方，不再新增 `AquaRegia` 材质。
2. **草酸不存在**：GT6CE 与 M3/M4 都没有草酸。金、硒、碲统一用 **SO₂ 还原**（工业上真实使用，且 M7 第 1 卡正好副产 SO₂），不新增草酸产线。
3. **氯金酸用粉**：`ChloroauricAcid` 在 GT6CE 里是 dust 材质，本卡用它承载王水溶解后的金，再还原成金粉。
4. **铑不单独做氯铑酸铵**：铑留在最后的 `RhodiumChlorideSolution` 里直接氢还原，少一层铵盐；其余五种都按总览的铵盐/络合物路线走。
5. **银不做电解精炼**：总览只要求“粗银”，本卡用铜置换直接产 `Silver` 粉；银电解留给以后需要超高纯银的卡（M8 唱片反射层可先用现有 `Silver`）。
