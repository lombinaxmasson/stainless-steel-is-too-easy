# M1「不锈钢没那么容易」计划卡总览

依据是 [`docs/supersymmetry-ssite-plan.md`](../supersymmetry-ssite-plan.md) 的 M0 与 M1 章节。目标是砍掉原版坩埚直炼不锈钢的捷径，实装专属 **AOD 精炼转炉**与**三级不锈钢体系**（`CarburizedStainlessSteel` 粗钢 $\rightarrow$ 原版 `StainlessSteel` 304 标准级 $\rightarrow$ `StainlessSteel316L` 化工耐蚀级），同时用空气硬吹低收率路线解开深冷塔空分的启动死锁。

还没有对外发布过，不做旧存档迁移。

```text
lane            = open
slug            = m1/index
```

## 卡

按这个顺序做。每张卡关闭时，`.\scripts\build.ps1`（Forge 1.20.1 与 NeoForge 1.21.1 双端编译与构建）都要通过，做完后移入 `docs/card-plans/closed/`。

| 顺序 | 卡 | 做完能看到什么 |
|---|---|---|
| 1 | [`砍掉不锈钢捷径与挂接服务`](closed/砍掉不锈钢捷径详细计划.md) | SPI 服务挂通；坩埚合不出原版不锈钢，搅拌机混不出不锈钢 |
| 2 | [`不锈钢冶金材料与 316L 管道`](closed/不锈钢冶金材料详细计划.md) | 铬铁、硅铁、高碳不锈钢、316L 钼不锈钢、铬盐与 316L 耐酸流体管进创造栏，中英文译名齐全 |
| 3 | [`AOD 转炉机器与配方表`](closed/AOD转炉机器详细计划.md) | `ssite:aod_converter` 机器方块与 `ssite.recipe.aod` 配方表注册成功，JEI/EMI 能看到转炉分页 |
| 4 | [`铬铁初炼与 AOD 三档精炼产线`](closed/不锈钢精炼产线详细计划.md) | 从铬铁矿、硅铁到坩埚初炼高碳粗钢，再到 AOD 空气/氮氧/氩氧三档吹炼 304 与纯氩炼 316L 全线跑通 |

第 1 到第 4 张卡做完，M0 + M1（v0.1 核心闭环）即可独立进游戏游玩。

## 明确不做

- 不改动原版上百个 HV 单方块机器和蒸馏塔/深冷塔的合成表材料 ID（原版 `StainlessSteel` 直接扮演二级 304 奥氏体不锈钢）
- 不在 M1 引入石化和水处理流体（留给 M2/M3 计划卡）
- 不自己写方块实体子类或接触 NBT，机器和管道统一走 GT6CE Addon SDK 的纯数据声明
